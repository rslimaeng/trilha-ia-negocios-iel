01
A ideia

Você testa primeiro, instrui depois

Em uma frase

Comece com o System Prompt vazio. Teste. Adicione 1 linha para corrigir o que observou. Teste de novo. Repita.

É como treinar um funcionário novo

Você não escreve o manual completo do funcionário antes de vê-lo trabalhar. Observa, vê o que ele faz errado, e corrige uma instrução por vez. System Prompt funciona igual.

  • O primeiro dia sem manual é o prompt vazio, que mostra o comportamento padrão
  • Observar ele atender é rodar com uma entrada real e ler a saída
  • A correção pontual é a linha que você acrescenta
  • O manual que existe no fim é o prompt, que ninguém teria escrito certo de primeira

Tentar escrever o prompt "perfeito" antes de qualquer teste quase sempre gera um agente que funciona nos seus exemplos imaginários e falha nos casos reais.

02
O ciclo

Seis passos, e o último volta ao terceiro

1System Prompt vazio
→
2Adicione 1 ferramenta e teste com 1 entrada real
→
3Observe: está no formato esperado? travou?
→
4Acrescente 1 linha que corrija aquilo
→
5Teste com a mesma entrada
e volte ao passo 3, até o comportamento ficar consistente

O passo 5 usa a mesma entrada de propósito. Trocar a entrada junto com o prompt é mudar duas coisas ao mesmo tempo, e aí você não sabe o que resolveu.

A penúltima linha é a única que não se resolve com prompt. Reconhecer isso economiza a tarde que se perde reescrevendo instrução para um problema que é de configuração.

04
As regras de ouro

Quatro, e a primeira é a que mais se quebra

1 · Nunca mude duas coisas ao mesmo tempo

Se mudar prompt e ferramenta e modelo, e parar de funcionar, você não sabe o que quebrou. Mude uma, teste, observe.

2 · Guarde as versões anteriores

Salve cada versão do prompt num arquivo. Quando uma alteração quebra o agente, você volta em segundos.

3 · Teste com caso de borda cedo

Se o agente só funciona com entrada perfeita, vai quebrar em produção. Use uma entrada incompleta antes de declarar pronto.

4 · Isto nunca termina

O prompt evolui com o uso real. Aceitar isso é o que separa o agente que funciona uma vez do que funciona sempre.
