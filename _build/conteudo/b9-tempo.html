Por que isso importa

Em uma frase

Esse é o primeiro fluxo do módulo que conversa com um sistema do mundo real fora do Google. Você sai de "Sheets + Gmail" e entra em "qualquer API HTTP".

O padrão Schedule → HTTP Request → Set → Gmail é o esqueleto de centenas de automações úteis: cotação do dólar, status de servidor, contagem de inscritos, painel de KPIs. Domina esse padrão e abre 90% dos casos de "puxar dado de fora".

A missão, em slide. A notificação do celular é o e-mail que a seção 04 mostra chegando; o "25/10" é a data do exemplo desenhado.

Passo a passo

Pré-requisitos
  • B8 concluído (sabe usar Edit Fields e expressions básicas).
  • Credencial Gmail configurada (ver aula 3).
  • Coordenadas da sua cidade (latitude e longitude). Fortaleza: -3.7172 / -38.5433. Pra outra cidade, abre Google Maps, clica com o botão direito sobre a cidade, copia as coordenadas.
Por que Open-Meteo e não OpenWeather?

Open-Meteo é gratuita e sem chave (até 10.000 chamadas/dia). Zero atrito de credencial: você abre o n8n e usa. OpenWeather é o "padrão da indústria", mas exige cadastro + API key. Pra primeira aula prática, Open-Meteo ganha.

Conferido em 16/09/2026 nos termos da Open-Meteo: "less than 10,000 API calls per day" pra uso não comercial, com 5.000 por hora e 600 por minuto.

4
Edit Fields: monta o texto do e-mail
  • Adiciona Edit Fields (Set). Renomeia: 📝 Monta Texto.
  • Mode: Manual Mapping.
  • Adiciona campo:
    • Nome: mensagem
    • Tipo: String
    • Valor: arrasta os campos do painel esquerdo, um por um, montando o texto:
O valor do campo mensagem 
🌤 Bom dia! Previsao pra Fortaleza:

Temperatura: {{ $json.current.temperature_2m }}°C
Umidade: {{ $json.current.relative_humidity_2m }}%
Vento: {{ $json.current.wind_speed_10m }} km/h

Tenha um bom dia.
Drag-and-drop puro

Você não digita {{ $json... }}: você arrasta o campo do painel esquerdo (em JSON view, dentro de current) e o n8n monta a expression sozinho. É o hábito que o módulo inteiro reforça.

  • Liga Keep Only Set (true) pra limpar os outros campos. Output fica só com mensagem.
  • Execute step. Confere o output.

Conferido na tela em 16/09/2026: na versão atual do nó Set, "Keep Only Set" virou a opção Include Other Input Fields, que fica desligada por padrão. Desligada, o output já sai só com mensagem.

6
Ativação

Quando o teste passou:

  • Clica em Activate (toggle no canto superior direito).
  • Workflow agora dispara sozinho amanhã 7h.

Conferido na tela em 16/09/2026: na versão atual o botão do canto superior direito se chama Publish; é ele que ativa. O toggle "Active" aparece na lista de workflows.

Lembrete do B7

Schedule Trigger só roda quando o workflow está ativado. No modo desativado, ele só dispara via "Execute Workflow" manual.

O que esperar
  • ✅ Quatro nós verdes depois do Execute Workflow.
  • ✅ Um e-mail na sua caixa com temperatura, umidade e vento de agora.
❌ Se o HTTP Request ficou vermelho

Vírgula nas coordenadas. A API usa ponto decimal (-3.7172). Confere a URL antes de mexer em outra coisa.

Não vale: apagar o nó e refazer. Lê o número do erro primeiro (aula 1): 400 é pedido malformado, e vírgula é pedido malformado.

06
A cerca

Pegadinhas

Coordenadas com vírgula

A API usa ponto decimal (-3.7172), não vírgula. Aluno BR copia do Google Maps com vírgula e dá erro.

weather_code é numérico

A doc da Open-Meteo tem tabela de códigos (0=céu limpo, 3=nublado, 61=chuva leve, etc.). Pra mostrar texto amigável, usa um Edit Fields com IF/Switch: bom exercício pra quem terminou B8.

Schedule só roda ativado

Workflow desativado não dispara: pra testar, usa "Execute Workflow" manual.

Pinar o HTTP Request enquanto monta o texto

Sem pinar, cada execução do workflow chama a API de novo. Em testes repetidos, vira gasto de chamada e tempo. Pino o nó depois da primeira execução boa, despino antes de ativar produção.
