03
O que você leva

Entregável do B8

1 fluxo de análise de dados rodando: lê uma planilha do Drive, agrupa por categoria, soma os valores, e te entrega um resumo formatado por e-mail. Você sai do B8 com um relatório automático que substitui a planilha-pivot manual de toda segunda 9h.

Mapa de Capacidades · B8

Marque com honestidade ao final do bloco. Se algum item ainda não estiver ✅, volte e revise antes de seguir pra B9.

  • Leio um JSON e identifico chave, valor, array, objeto aninhado.
  • Identifico um erro de tipo de dado no JSON view (string vs number) e converto com Number() / String().
  • Uso Set / Edit Fields com Keep Only Set ligado pra limpar dados antes da próxima etapa.
  • Pinno o output de um nó (P) pra iterar nos próximos sem reexecutar tudo, e despinno antes de ativar produção.
  • Escrevo {{ $json.campo }} arrastando do painel de input, sem decorar sintaxe.
  • Configuro o nó IF com condição e dois ramos; testo os dois lados.
  • Decido entre IF (2 caminhos) e Switch (3+ caminhos), e nunca esqueço o Fallback do Switch.
  • Escolho o modo certo do Merge (Choose Branch vs Combine by Position) explicando por quê.
  • Uso Split Out pra explodir um array em itens e Aggregate pra juntar de volta.
  • Construí o fluxo prático "Resumo semanal de vendas" sozinho: Sheets → Summarize → Sort → Aggregate → Set → Gmail.
04
Confira

Protocolo de Validação: fluxos do B8

Antes de declarar que o fluxo está "pronto":
  1. Sem nó vermelho: todos executaram em verde, sem warnings de tipo.
  2. Output esperado: o e-mail/output chegou com os dados certos: categorias ordenadas, valores formatados com 2 casas decimais, total geral conferindo.
  3. Caso de borda testado: duplique uma linha da planilha (mesmo produto, mesma categoria) e rode de novo. O count daquela categoria deve aumentar em 1, o sum deve refletir.
