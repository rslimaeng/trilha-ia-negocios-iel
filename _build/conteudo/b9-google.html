01
O que você vai aprender

Por que isso importa

Em uma frase

Quem domina os 3 monta 80% dos fluxos do mundo profissional sem precisar de mais ferramenta.

E-mail é o canal mais universal de notificação. Sheets é o "banco de dados do iniciante": persistência grátis sem virar dev. Drive é onde os arquivos do dia-a-dia ficam (PDFs, currículos, planilhas pra processar). Os 3 compartilham a mesma OAuth do Google, então o setup é uma vez só.

Conceito central: uma OAuth, três nós

O conceito desta aula

Google OAuth (1 credencial)
    ├── Gmail node      → enviar/ler e-mail
    ├── Sheets node     → ler/escrever planilha
    └── Drive node      → manipular arquivos
Setup-chave

Ao criar a credencial Gmail, ative os escopos também pra Sheets e Drive. Assim a mesma credencial serve aos 3. Aprofundamento na aula 3 (Credenciais).

Uma chave, três cadeados, em slide. Leia o aviso abaixo antes de procurar a chave única na lista do n8n.

Conferido na tela em 16/09/2026: o que "uma credencial" quer dizer no n8n de hoje

Na aba Credentials da conta do instrutor aparecem quatro credenciais Google separadas, uma por tipo: "gmail-rslima" (Gmail OAuth2 API), "google-sheet-rslima" (Google Sheets OAuth2 API), "google-drive-rslima" (Google Drive OAuth2 API) e "google-docs-rslima" (Google Docs OAuth2 API). O nó Gmail só aceita credencial do tipo Gmail OAuth2, o nó Sheets só aceita Google Sheets OAuth2, e assim por diante: não dá pra escolher a credencial do Gmail dentro do nó Sheets. O que se cria uma vez e se reaproveita é o lado do Google: o mesmo projeto no Cloud Console, o mesmo Client ID e Client Secret e o mesmo "Sign in with Google". A chave única do slide é essa; na lista do n8n ela aparece como uma entrada por serviço.

Configuração mínima do Send

  1. Operation: Send
  2. To: e-mail destino (Fixed ou Expression {{ $json.email }})
  3. Subject: assunto (Expression: Olá {{ $json.nome }} — relatório semanal)
  4. Email Type: Text ou HTML (HTML pra formato rico)
  5. Message: corpo do e-mail (Expression suportada)

Pegadinhas Gmail

  • OAuth precisa de domínio verificado pra produção. Em testes, conta pessoal funciona; pra mandar de domínio empresarial, configura GCP.
  • HTML vs Plain text. Se mandar HTML em Plain, sai com tags visíveis. Se mandar Plain em HTML, perde formatação.
  • Limite diário do Gmail: 500 e-mails/dia em conta gratuita; 2000/dia em Workspace pago.

Pegadinhas Sheets

  • Compartilhamento da planilha: precisa estar acessível pela conta conectada na credencial.
  • Header row vs data row. A primeira linha vira nomes de coluna (chaves no JSON). Se não tem header, n8n usa A/B/C.
  • Update por linha vs por valor de coluna-chave. Update tem 2 modos: por número de linha (frágil) ou por valor de coluna (email = "ana@x.com": mais robusto).

Google Drive: arquivos

Operações principais

OperaçãoPra que serve
DownloadBaixar pra processar (vira binário no n8n)
Move / Share / DeleteOrganização e gestão

O export do Notion perdeu linhas desta tabela também: a pegadinha do fim manda usar uma operação List que não está nela.

Configuração mínima do Download

  1. Operation: Download.
  2. File: selecione pelo ID ou via Expression ({{ $json.fileId }}).
  3. Output do nó vira binário, acessível por nó seguinte (ex.: AI Agent que extrai texto de PDF).

Pegadinhas Drive

  • Permissões: arquivo precisa estar acessível pela conta da credencial.
  • Tamanho do arquivo no Cloud: n8n Cloud tem limite de execução por tempo/memória. Arquivos grandes (>50MB) podem estourar.
  • fileId vs nome: n8n usa fileId interno do Google. Pra pegar o ID, navegue pela árvore na configuração ou use uma operação List antes.

05
A cerca

Pegadinhas gerais

Configurar 3 credenciais Google separadas

Desnecessário e confuso. Use uma só com escopos amplos.

Leia com o aviso da seção 02: no n8n de hoje a lista mostra uma entrada por serviço; "uma só" é o projeto e o cliente OAuth no Google.

OAuth expira

Depois de inatividade, o Google revoga. Sintoma: erro 401 em produção. Solução: reconectar credencial.

Esquecer de checar limites de plano gratuito

Gmail (500/dia), Sheets (10M células). Conta pessoal estoura mais fácil que parece em fluxo automatizado.
