Aqui o curso muda de patamar

Aqui o curso muda de patamar. Você sai do "automação que segue regras" pro "automação que decide". E aprende uma coisa que separa quem vende automação genérica de quem entrega ROI: AI Agent é uma das ferramentas, não a única. O n8n tem 6 nós de IA, e saber escolher o certo pra cada caso é o maior diferencial competitivo que você sai do curso.

Objetivo do bloco

Dominar AI Agent (Brain + System Prompt + Memory + Tools) com Reactive Prompting e Session ID dinâmico, mais os 4 nós de IA "leve" (Information Extractor, Text Classifier, Summarization Chain, Sentiment Analysis) que cobrem 60% dos casos práticos com 1/3 do custo de um Agent.

"60% dos casos" e "1/3 do custo" são afirmações do material, de abril de 2026, sem fonte declarada; entram como estão.

O que você leva

Mapa de Capacidades · B10

Ao final, você consegue:

  • Explicar em uma frase a diferença entre AI Agent e os outros 5 nós de IA do n8n.
  • Identificar os 4 componentes internos do AI Agent e diagnosticar qual está com bug.
  • Aplicar Reactive Prompting: começar vazio, testar, corrigir 1 linha por vez.
  • Escrever System Prompt em 6 partes (ROLE/GOAL/TOOLS/RULES/NOTES/OUTPUT).
  • Configurar Session ID dinâmico (nunca fixo em produção).
  • Adicionar uma tool ao agente com $fromAI() e referenciá-la no System Prompt.
  • Saber quando NÃO usar AI Agent: Information Extractor / Text Classifier / Summarization Chain / Sentiment Analysis no caso certo.
  • Construir pelo menos 3 dos 5 fluxos práticos sozinho (1 conversacional, 1 com Agent + tools, 1 sem Agent).
  • Diagnosticar no painel de execuções qual caminho/tool foi usado e por quê.
03
Confira

Protocolo de Validação para cada agente

O agente está válido quando:
  1. Nenhum nó vermelho.
  2. Output JSON tem todos os campos esperados.
  3. Caso de borda testado: input incompleto.

Plus: teste de isolamento de sessão: outro usuário recebe contexto isolado, não os seus dados.
