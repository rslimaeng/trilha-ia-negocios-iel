O que tem dentro

Os blocos deste módulo

A mesma rotina que você escolheu no Módulo 1 volta aqui, agora para rodar sozinha. O módulo começa antes da ferramenta: primeiro o modelo mental de gatilho, execução e entrega, e só depois a tela do n8n. Os blocos entram um a um, na ordem abaixo: o que já está aberto tem o link; o resto está em produção.

05

Antes do n8n: pensar como automação

Transformar uma tarefa repetitiva real em um mapa textual claro (Gatilho → Execução → Entrega), pronto pra virar workflow no B6. Sem n8n aberto.

1 processo seu mapeado em texto abrir →
06

Fundamentos do n8n

Navegar o n8n com fluência, entender a anatomia de um workflow, executar o primeiro fluxo do zero e ver um AI Agent funcionando como teaser do B10.

5 nós dominados + 1 mini-agente no chat abrir →
07

Gatilhos

Escolher o trigger certo pra cada caso (manual / schedule / webhook / form / app event), configurar e testar cada um do zero, e construir 1 fluxo prático completo (Lembrete diário automático).

Em produção
08

Execução (dados, lógica, controle)

Ler JSON com fluência, transformar campos com Set, escrever expressions, tomar decisões com IF/Switch, juntar caminhos com Merge e manipular listas com Split Out / Aggregate, culminando num fluxo prático de análise de dados.

Em produção
09

APIs e webhooks

Explicar API sem jargão, dominar HTTP Request (4 verbos + Import cURL), configurar OAuth/API Key/Header Auth, usar os 3 nós Google na mesma credencial, e construir mini-API com Respond to Webhook.

Em produção
10

AI Agents (single-agent)

Dominar AI Agent (Brain + System Prompt + Memory + Tools) com Reactive Prompting e Session ID dinâmico, mais os 4 nós de IA "leve" (Information Extractor, Text Classifier, Summarization Chain, Sentiment Analysis) que cobrem 60% dos casos práticos com 1/3 do custo de um Agent.

Em produção
11

Projetos integradores e IA co-criando fluxos

Ter pelo menos 1 workflow real rodando com tratamento de erro e ativação adequada, escolhido por você entre os 4 projetos guiados, mais sair com a habilidade de descrever processo em linguagem natural → IA gera o JSON → você ajusta.

Em produção
12

Recursos Profissionais

Dominar 3 práticas que separam o usuário casual do profissional de automação: organização com sub-workflows, prototipação rápida com IA gerando JSON, e construção avançada com Claude Code.

Em produção
