Por que isso importa

Em uma frase

A pergunta certa não é "quanto AI Agent posso colocar no fluxo?". É "qual nó de IA é o mínimo necessário?".

Os 4 nós deste tópico fazem uma coisa só com extrema previsibilidade. Não precisam de System Prompt elaborado, não consomem tokens em loop, não inventam ação.

Um número: workflow que recebe 1.000 e-mails/dia e classifica em 4 categorias custa R$ 5/mês com Text Classifier vs R$ 25-40/mês com AI Agent. Mesma saída, custo 5x.

Os números desta aula ("60%", "1/3", "R$ 5", "R$ 25-40", "5x") são afirmações do material, de abril de 2026, sem fonte declarada; entram como estão. Preço de modelo muda a cada mês.

03
Como funciona

Os 4 nós em detalhe

1. Information Extractor: "extrai campos estruturados de texto bagunçado"

O que faz: recebe texto livre (PDF, e-mail, mensagem, currículo) e retorna JSON com os campos que você definiu.

Quando usar:

  • Currículo em PDF → extrai nome, cargo_atual, anos_experiencia, email.
  • Nota fiscal em texto → extrai cnpj, valor_total, data_emissao, itens.
  • Ata de reunião → extrai data, participantes, decisoes, proximos_passos.
  • Mensagem de cliente WhatsApp → extrai intencao, produto_mencionado, urgencia.

Caso típico: o Fluxo prático 4 usa exatamente isso pra triar atas de reunião → Sheets.

2. Text Classifier: "põe num balde com nome"

O que faz: recebe texto e classifica em uma das categorias que você definiu. Não inventa categoria nova.

Quando usar:

  • E-mail entrante → Suporte, Vendas, Financeiro, Spam.
  • Mensagem de cliente → Reclamação, Elogio, Dúvida, Outros.
  • Lead → Qualificado, Não-qualificado, Reabrir-em-90-dias.

Saída: o nó conecta múltiplas saídas (uma por categoria), como Switch nativo.

Caso típico: o Fluxo prático 5 classifica caixa de entrada toda manhã.

3. Summarization Chain: "encolhe texto sem perder o essencial"

O que faz: recebe texto longo (5 páginas, thread de 30 mensagens, transcrição de reunião) e devolve um resumo.

Quando usar:

  • Reunião gravada → transcrição → Summarize → 3 bullets pro Slack.
  • Thread longa de cliente → resumo executivo na sua caixa.
  • Relatório PDF de 20 páginas → 1 parágrafo.

4. Sentiment Analysis: "está positivo ou negativo?"

O que faz: classifica o tom emocional do texto: positivo, neutro, negativo (com confidence opcional).

Quando usar:

  • Pesquisa NPS aberta → identifica detratores antes de cancelarem.
  • Comentários de Instagram → detecta pico de negativos depois de post.
  • Feedback interno → termômetro do time.
04
A demonstração

Como funciona na prática: Information Extractor passo a passo

Uma ata em texto, cinco campos em JSON, um nó

1. Setup

Workflow novo. Manual Trigger → Edit Fields com texto:

O texto do Edit Fields 
Reunião do projeto ERP em 15/03/2026.
Participantes: João Silva (Diretor TI), Maria Costa (PM),
Pedro Almeida (Fornecedor SAP). Decidimos prorrogar o go-live
pra junho. Próximo passo: Maria envia plano revisado até 22/03.

2. Information Extractor

Schema (manual): 5 atributos:

  • data, string, "Data no formato dd/MM/yyyy"
  • projeto, string, "Nome do projeto"
  • participantes, array, "Lista de nomes"
  • decisao, string, "Decisão principal"
  • proximo_passo, string, "Próximo passo + responsável"

Conferido em 21/09/2026 na definição do nó (Information Extractor 1.2): no modo Attributes os tipos são string, number, boolean e date. Pra um campo de lista como participantes (array), o schema vai em Define using JSON Schema ou From JSON example.

3. Chat Model

Adiciona OpenAI Chat Model com gpt-4o-mini (ou Gemini Flash).

4. Executar

O JSON que sai 
{
  "data": "15/03/2026",
  "projeto": "ERP",
  "participantes": ["João Silva", "Maria Costa", "Pedro Almeida"],
  "decisao": "Prorrogar o go-live pra junho",
  "proximo_passo": "Maria envia plano revisado até 22/03"
}

Você acabou de fazer com 1 nó o que um AI Agent levaria 4 chamadas pra fazer. Mesmo resultado, fração do custo, zero loop.

Não rodado em 09/2026: os quatro passos e o JSON são o caminho do material, sem execução numa conta de teste. Nome de modelo é de abril de 2026; a porta gratuita desta turma é a do B6, aula 5.

05
A cerca

Pegadinhas

Schema vago

Cada campo precisa de descrição clara: tipo, formato, o que esperar.

Pedir campo que não existe no texto

O nó pode inventar valor. Solução: na descrição escreva "deixe vazio se não estiver presente".

Usar AI Agent pra tarefa de extração

Workflow mais caro e mais lento, mesma saída. Reflexo do iniciante.

Text Classifier com categorias com nomes parecidos

"Suporte técnico" vs "Suporte ao cliente" → confunde.

Sentiment Analysis com sarcasmo

"Adorei esperar 3 horas" classifica como positivo (literal).

Esquecer de conectar Chat Model nos 4 nós

São cluster nodes: precisam de Chat Model na porta inferior.

Quando AI Agent ainda é o certo

Agent é o certo quando:

  • O fluxo precisa decidir e agir em sistemas externos.
  • Você precisa de conversa multi-turno com memória.
  • Os passos são dinâmicos: não dá pra prever quantas tools chamar nem em qual ordem.

Nos 4 outros casos (extrair, classificar, resumir, analisar tom), prefere o nó especializado.
