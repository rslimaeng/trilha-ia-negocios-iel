Nesta aula
O que você vai construir:
  • Form Trigger que recebe upload de PDF de ata de reunião → Extract from File lê o texto do PDF → Information Extractor extrai 5 campos estruturados → Google Sheets registra cada ata como uma linha nova. Em 4 nós, sem Agent.
01
O que você vai aprender

Por que isso vale a pena

Em uma frase

Ler ata de reunião, copiar campos pra planilha, repetir 5 vezes por semana = 2-3h/mês de trabalho braçal de PMO/admin.

Esse fluxo faz isso em 3 segundos por documento, com Information Extractor: sem AI Agent, sem System Prompt, sem loop. É o caso "trocar trabalho repetitivo por upload de arquivo" que mais vende automação no mundo profissional. E prova o ponto da aula 6: nem tudo precisa de Agent.

"2-3h/mês", "3 segundos" e "6h/mês" são estimativas do autor, de abril de 2026.

O conceito desta aula

Information Extractor
  • Adiciona Information Extractor. Renomeia: 🤖 Extrai Campos.
  • Text: {{ $json.text }}.
  • Schema (manual): 5 atributos:
NomeTipoDescrição
datastringData da reunião no formato dd/MM/yyyy. Se aparecer escrito por extenso, converte. Se não estiver presente, deixe vazio.
projetostringNome do projeto ou iniciativa discutida.
participantesarrayLista dos nomes dos participantes (sem cargos).
decisoesarrayLista das decisões tomadas. Cada item é uma frase curta.
proximos_passosarrayLista dos próximos passos com responsável e data quando mencionados.

A tabela veio embaralhada no export (seis colunas, linhas fundidas) e foi remontada com as palavras que vieram: cinco atributos, três colunas. Conferido em 21/09/2026 na definição do nó (Information Extractor 1.2): no modo Attributes os tipos são string, number, boolean e date; pros três campos de lista (array) o schema vai em Define using JSON Schema ou From JSON example. O nome do nó com emoji não foi testado nesta família de nós: se aparecer o erro Custom date key que o AI Agent dá (B6, aula 5), tire o emoji.

06
A cerca

Pegadinhas

PDF escaneado (imagem) sem OCR

Extract from File só lê PDF "real" (texto vetorial).

Schema com descrição vaga

"data: a data" → formato inconsistente. Sempre especifique formato esperado.

Não tratar campo opcional

Se a ata não tem proximos_passos, o Extractor pode inventar. Solução: na descrição escreva "deixe vazio se não estiver presente".

Array virando string sem .join()

Sheets vê [object Object]. Sempre use .join() pra serializar arrays em texto.

Form Trigger em modo Test só fica vivo enquanto você está com o n8n aberto

Pra deixar a URL pública, ativa o workflow.
