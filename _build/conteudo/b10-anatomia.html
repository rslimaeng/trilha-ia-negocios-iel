O que você vai aprender

Por que isso importa

Em uma frase

O AI Agent node é o nó mais poderoso do n8n, e o mais diferente de tudo que você viu do B6 ao B9. Ele não segue um fluxo fixo. Ele decide.

Quem entende como ele é composto por dentro consegue construir, depurar e evoluir o agente sozinho. Quem não entende fica refém de tutorial: funciona uma vez, quebra na segunda, e o aluno não sabe por onde começar a investigar.

Conceito central

O conceito desta aula

Por dentro, o AI Agent são 4 sub-sistemas

Quando você arrasta o AI Agent pro canvas, ele parece um nó simples. Por dentro, são 4 sub-sistemas que trabalham juntos.

Analogia: o funcionário especializado

Pense no AI Agent como contratar um funcionário especializado: ele não vem sozinho.

  • LLM = o cérebro
  • System Prompt = o manual do primeiro dia
  • Memória = o caderno de anotações
  • Tools = o que o agente pode fazer
AI Agent node
  • LLM (modelo de linguagem)
  • System Prompt (instruções)
  • Memória (lembra contexto)
  • Tools (o que pode fazer)

LLM: o cérebro

O modelo de IA que processa linguagem: GPT-4o, Claude Sonnet, Gemini. Recebe o contexto e decide o que fazer.

ModeloCustoQuando usar
GPT-4oMédioTarefa complexa, raciocínio longo.
Gemini FlashBaixoIntegração Google Workspace.
Iniciante começa com GPT-4o-mini

É como contratar um analista júnior competente: barato e suficiente pra maioria das tarefas.

Nomes de modelo e custo são de abril de 2026. A porta gratuita desta turma é a do B6, aula 5: Gemini pela chave do Google AI Studio (conferida em 16/09/2026) ou OpenRouter. O papel do "júnior" continua o mesmo: comece pelo modelo mais barato.

System Prompt: o manual do primeiro dia

Conjunto de instruções permanentes que definem como o agente se comporta. Lido antes de tudo. O que está aqui tem mais peso do que qualquer outra coisa.

Analogia: o manual de integração que você entrega ao funcionário no primeiro dia. "Leia isso antes de atender qualquer cliente."

System Prompt vazio = funcionário sem treinamento: tecnicamente capaz, na prática imprevisível. Sempre escreva pelo menos uma linha. Aprofundamento na aula 3.

Memória: o caderno de anotações

Controla o que o agente lembra dentro de uma conversa. Sem memória, cada mensagem é tratada como se fosse a primeira: o agente esquece quem você é a cada execução.

Tipo recomendado pra v1: Simple Memory (guarda últimas N mensagens da sessão).

Configuração crítica: o Session ID. Ele separa conversas de pessoas diferentes. Se ficar fixo, o agente mistura dados de todo mundo. Aprofundamento na aula 5.

Tools: o que o agente pode fazer

Ações concretas que o agente decide chamar quando precisa: ler planilha, enviar e-mail, buscar arquivo, consultar API. Você não conecta com IF: o LLM olha pro System Prompt, vê quais ferramentas tem, e escolhe.

Boa prática: comece com 1 tool. Teste. Adicione a próxima. Aprofundamento na aula 4.

Como funciona

Como funciona na prática: o ciclo de raciocínio

Quando o agente recebe uma mensagem, ele faz um loop interno que você não programa:

0
Input

Mensagem do usuário ou dado da planilha

→
1
Recupera

Recupera memória

Últimas N mensagens da mesma sessão.

→
2
Lê

LLM lê

System Prompt + memória + mensagem atual.

→
3
Decide

LLM decide: preciso usar uma tool?

NÃO → formula a resposta final.

→
4
Output

Resposta + salva interação na memória

SIM → chama tool → recebe resultado → volta a decidir (pode repetir).

Esse loop é o que torna o agente diferente de um nó comum. Ele pode chamar uma ferramenta várias vezes antes de produzir a resposta final.

04
A demonstração

Visualizando o ciclo no painel de execuções

Quando o agente roda, o n8n mostra cada decisão que ele tomou
  • Caminho verde → a ferramenta foi chamada nesta execução.
  • Caminho cinza → a ferramenta não foi chamada.
Modelo mental crítico

Se a tool deveria ter sido chamada e o caminho ficou cinza, o problema não é o LLM: é que a tool não está mencionada no System Prompt, ou a descrição dela está ambígua.

Não rodado em 09/2026: nenhum agente com tool foi executado numa conta de teste para este bloco; o painel verde e cinza aqui é o que o material descreve, sem print.

Pegadinhas

Esquecer Session ID dinâmico

System Prompt vazio em produção

Agente improvisa formato a cada execução.

Sem tool

Agente promete e não cumpre. Diz "vou agendar pra você" e não agenda.

Tool com nome/descrição vagos

Agente confunde quando usar.
