As 3 visões do output (Schema / Table / JSON)

Quando você executa um nó e olha o painel da direita (Output), pode trocar entre 3 formatos de visualização:

VisãoO que mostraQuando usar
SchemaEstrutura: nomes dos campos + tipo de cada (String, Number, Array...). Compacto.Pra entender o formato dos dados rapidamente.
TableLinhas e colunas, como uma planilha.Quando os dados são uma lista de objetos parecidos (ex.: leads, contatos).
JSONO dado cru, como código.Pra ver detalhes ou copiar valor exato.

As três lentes, como foram mostradas em sala. A dica de baixo é o hábito do aviso a seguir: Schema primeiro, JSON só quando precisar do valor.

Hábito útil

Comece pela Schema view (visão geral), confirme o formato. Pula pra JSON só quando precisar copiar/inspecionar valor específico.

03
Como funciona

Como funciona na prática

Pré-requisitos

Conta n8n Cloud criada (sem precisar de credencial nenhuma nesta aula).

Os quatro passos em um slide, como foram mostrados em sala. Abaixo, o mesmo caminho em sete passos, com os nomes exatos de cada campo.

1
Crie um workflow novo

Workflows → + Add workflow. Renomeie pra Meu Primeiro Fluxo.

2
Adicione um Manual Trigger

Clique duplo no canvas → busque "Manual Trigger" → adicione. Renomeie pra ▶️ Disparo Manual.

3
Adicione um Set (Edit Fields)

Clique no + à direita do Manual Trigger → busque "Edit Fields" → adicione. Renomeie pra 📦 Meus Dados.

4
Configure o Set com 3 campos

No painel do nó:

  • Em Mode, deixe Manual Mapping.
  • Clique em + Add Field:
Os 3 campos · nome, tipo e valor 
Name: mensagem  · Type: String · Value: Meu primeiro fluxo no n8n!
Name: data      · Type: String · Value: {{ $now }}
Name: meu_nome  · Type: String · Value: (seu nome)
5
Execute o workflow

Clique em Execute Workflow (canto superior direito) ou aperte Ctrl + Enter.

Não clicar em "Execute Workflow" e ficar esperando

O n8n não roda automaticamente em modo manual. Você precisa clicar pra disparar.

Não vale: achar que precisa de credencial pra começar. Manual Trigger + Set = zero credencial. Você só precisa de credencial quando vai conectar com app externo (Gmail, Sheets, OpenAI). Esses entram no B7/B9.
6
Veja o resultado

Clique no nó 📦 Meus Dados → painel da direita → Output.

O que você vê em cada visão:
  • Em Schema: você vê mensagem (String), data (String), meu_nome (String).
  • Em Table: vê uma linha com os 3 campos.
  • Em JSON: vê o objeto completo (o da demonstração abaixo, com a sua data e o seu nome).
7
Pinne o output

Com o Set selecionado, aperte P. Aparece um pino: o output fica fixado, e os próximos testes não precisam re-executar.

Pronto. Você executou seu primeiro workflow.

Variações pra exercitar

8
Variação 1: adicione mais campos com tipos diferentes

Volte no Set, adicione:

9
Variação 2: encadeie um segundo Set com expression
  1. Adicione mais um Edit Fields depois do primeiro. Renomeie pra 🧹 Adiciona Saudação.
  2. No campo mensagem, em vez de digitar texto fixo, arraste o campo meu_nome do painel esquerdo (lista de dados de entrada). Vai aparecer algo como {{ $('📦 Meus Dados').item.json.meu_nome }}: esse é o seu primeiro contato com expression.
  3. Antes do {{ ... }}, digite: Olá, e depois do }}, !. O valor final fica algo tipo:
O valor do campo mensagem · com a expression 
Olá, {{ $('📦 Meus Dados').item.json.meu_nome }}!
  1. Execute.
  2. Olhe o output do segundo Set: o campo mensagem agora tem o seu nome dentro.
Você acabou de usar uma expression

O {{ ... }} é o jeito do n8n falar "pega esse dado dinâmico aqui". Você não precisou digitar a sintaxe: o n8n formou ela sozinho quando você arrastou o campo. Isso vai virar pão-com-manteiga lá pelo B8. Por enquanto, basta ver que funciona e que a expression se monta sozinha via drag-and-drop.

O arrasto, em slide. O nome dentro do campo é o do instrutor, que fez o exemplo em sala; na sua conta, o campo tem o seu. E a expression do slide é a forma curta ($json); a que o arrasto monta na variação 2 nomeia o nó de origem, e as duas funcionam.

Exemplo guiado · o canvas com as duas variações

Redesenho do canvas depois das duas variações (execução 401, 16/09/2026). O output do segundo Set saiu com "mensagem": "Olá, (seu nome)!" e os seis campos do primeiro, com idade como número e gosta_de_n8n como true.

A cerca

Pegadinhas

Confundir o painel de Output com o de Input

Toda janela de nó tem 2 abas (Input à esquerda, Output à direita). Input mostra o que chegou pro nó; Output mostra o que saiu. Se você acabou de configurar e quer ver o resultado, vá no Output.

Esquecer de salvar

O n8n auto-salva, mas se você fechar a aba antes do Saved aparecer (ícone "Saving..." some), pode perder mudanças. Aguarde o Saved.

Misturar tipos no Set (digitar número como String)

Se você marcar o campo como Number e digitar "10" (com aspas), o n8n vai entender como String. Faz toda diferença depois: IF, Filter, comparações de número quebram silenciosamente quando o tipo está errado. B8 destrincha isso.
