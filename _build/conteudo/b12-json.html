01
O que você vai aprender

Por que isso importa

Em uma frase

A IA não vai construir o fluxo perfeito. Mas monta o esqueleto, e o tempo cai pela metade.

Você já sabe construir fluxos. Mas às vezes o esboço está na cabeça e você quer sair do zero mais rápido, sem arrastar nó a nó desde o início.

Ela entrega os nós certos, na ordem certa, com os parâmetros principais preenchidos. Você importa, conecta credenciais, testa e ajusta.

É como o móvel que vem desmontado

A caixa traz todas as peças cortadas na medida e o desenho de como elas se encaixam. Ninguém chama de defeito o fato de você precisar montar: o serrote já foi feito, que é a parte difícil e demorada. O que sobra é o parafuso, e o parafuso depende da sua parede.

  • As peças cortadas são os nós certos na ordem certa
  • O desenho de montagem são as conexões entre eles
  • Os parafusos que você põe são as credenciais e os seus identificadores
  • A sua parede é o seu processo, que a fábrica não tem como conhecer
Dois números diferentes, nos dois materiais

Esta página do material estima 80% acerto e 20% ajuste; a aula 5 do B11 fala em 70% e 30%. As duas afirmações são do autor, de abril de 2026, e entram como estão. A leitura que serve para os dois casos é a mesma: a estrutura vem pronta, os detalhes são seus.

Os três pedidos começam por uma entrevista: a IA pergunta uma coisa de cada vez e só gera quando você disser que pode. É de propósito, e é o que impede ela de preencher com suposição o que você não disse.

Usar a V1 num fluxo com IF sai errado

O IF tem duas saídas, e o formato das conexões é diferente do fluxo linear. Cada versão traz o molde certo já pronto; escolher a errada produz um fluxo que importa e não funciona.

V1 · fluxo linear

Pedido V1 · sem decisões e sem IA 
Você é um especialista em n8n, plataforma de automação low-code.
Seu objetivo é me ajudar a criar um workflow linear simples, gerando no final
um JSON válido que eu possa importar diretamente no n8n.

REGRA PRINCIPAL: Não gere o JSON ainda. Faça uma entrevista comigo primeiro.
Faça UMA pergunta por vez. Só gere o JSON quando eu disser "pode gerar".

--- ENTREVISTA ---

1. "O que este workflow precisa fazer? Descreva em 1 ou 2 frases."
2. "Como este workflow começa?
   (A) Formulário  (B) Agendamento  (C) Webhook  (D) Manual  (E) Outro"
3. "Quais informações chegam no início? (ex: nome, e-mail, valor...)"
4. "Quais ferramentas ele usa? (ex: Gmail, Sheets, HTTP API...)"
5. "O que acontece na última ação?"

Depois, resuma o que entendeu e pergunte se está correto.

--- GERAÇÃO DO JSON ---

Siga exatamente este modelo de estrutura:

{
  "name": "Nome do Workflow",
  "nodes": [
    {
      "id": "trigger-1",
      "name": "Início",
      "type": "n8n-nodes-base.manualTrigger",
      "typeVersion": 1,
      "position": [240, 300],
      "parameters": {}
    },
    {
      "id": "gmail-2",
      "name": "Envia E-mail",
      "type": "n8n-nodes-base.gmail",
      "typeVersion": 2.1,
      "position": [540, 300],
      "parameters": {
        "resource": "message",
        "operation": "send",
        "sendTo": "email@exemplo.com",
        "subject": "Assunto",
        "message": "={{ $json.campo }}",
        "emailType": "text"
      }
    }
  ],
  "connections": {
    "Início": {
      "main": [[{"node": "Envia E-mail", "type": "main", "index": 0}]]
    }
  },
  "settings": {"executionOrder": "v1"}
}

REGRAS:
- id: string curta e única por nó (ex: "trigger-1", "gmail-2")
- position: x começa em 240, incrementa 300 a cada nó. y fixo em 300.
- connections: a chave é o campo "name" exato do nó de origem
- Dados dinâmicos: use ={{ $json.nome_campo }} para referenciar campos anteriores
- Não inclua o campo "credentials"

NÓS DISPONÍVEIS:
- Formulário: n8n-nodes-base.formTrigger (v2.2)
- Agendamento: n8n-nodes-base.scheduleTrigger (v1.1)
- Webhook: n8n-nodes-base.webhook (v1.1)
- Manual: n8n-nodes-base.manualTrigger (v1)
- Gmail: n8n-nodes-base.gmail (v2.1) — resource: message, operation: send
- Google Sheets: n8n-nodes-base.googleSheets (v4.1)
- Google Docs: n8n-nodes-base.googleDocs (v2)
- HTTP Request: n8n-nodes-base.httpRequest (v4.2)
- Edit Fields (Set): n8n-nodes-base.set (v3.4)

APÓS O JSON, inclua obrigatoriamente:
1. Credenciais para configurar — quais nós precisam de credencial
2. O que ajustar — IDs reais, expressões que precisam revisão
3. Como importar: n8n → ícone de menu → Import from JSON

V2 · fluxo com decisões

Pedido V2 · com IF ou Switch 
Você é um especialista em n8n, plataforma de automação low-code.
Seu objetivo é me ajudar a criar um workflow com lógica de decisão (IF ou Switch),
gerando no final um JSON válido que eu possa importar no n8n.

REGRA PRINCIPAL: Não gere o JSON ainda. Faça uma entrevista comigo primeiro.
Faça UMA pergunta por vez. Só gere o JSON quando eu disser "pode gerar".

--- ENTREVISTA ---

1. "O que este workflow precisa fazer? Descreva em 1 ou 2 frases."
2. "Como este workflow começa?
   (A) Formulário  (B) Agendamento  (C) Webhook  (D) Manual  (E) Outro"
3. "Quais informações chegam no início?"
4. "Quais ferramentas ele usa?"
5. "Descreva a decisão: qual condição é verificada e o que acontece em cada caminho?"
6. "O que cada caminho entrega ao final?"

Depois, resuma o que entendeu e pergunte se está correto.

--- GERAÇÃO DO JSON ---

ATENÇÃO: IF e Switch têm múltiplas saídas. O formato de connections é diferente de um fluxo linear.
Siga exatamente este modelo:

{
  "name": "Workflow com Decisão",
  "nodes": [
    {
      "id": "trigger-1",
      "name": "Início",
      "type": "n8n-nodes-base.manualTrigger",
      "typeVersion": 1,
      "position": [240, 300],
      "parameters": {}
    },
    {
      "id": "if-2",
      "name": "Verifica Condição",
      "type": "n8n-nodes-base.if",
      "typeVersion": 2,
      "position": [540, 300],
      "parameters": {
        "conditions": {
          "options": {"caseSensitive": true, "leftValue": "", "typeValidation": "strict"},
          "conditions": [
            {
              "id": "cond-1",
              "leftValue": "={{ $json.campo }}",
              "rightValue": "valor_esperado",
              "operator": {"type": "string", "operation": "equals"}
            }
          ]
        }
      }
    },
    {
      "id": "set-3a",
      "name": "Caminho Verdadeiro",
      "type": "n8n-nodes-base.set",
      "typeVersion": 3.4,
      "position": [840, 160],
      "parameters": {}
    },
    {
      "id": "set-3b",
      "name": "Caminho Falso",
      "type": "n8n-nodes-base.set",
      "typeVersion": 3.4,
      "position": [840, 440],
      "parameters": {}
    }
  ],
  "connections": {
    "Início": {
      "main": [[{"node": "Verifica Condição", "type": "main", "index": 0}]]
    },
    "Verifica Condição": {
      "main": [
        [{"node": "Caminho Verdadeiro", "type": "main", "index": 0}],
        [{"node": "Caminho Falso", "type": "main", "index": 0}]
      ]
    }
  },
  "settings": {"executionOrder": "v1"}
}

REGRAS:
- id: string curta e única por nó
- O IF tem DOIS arrays dentro de "main": o primeiro é verdadeiro, o segundo é falso
- Para Switch com 3+ caminhos, adicione mais arrays em "main"
- position: nós do mesmo nível ficam no mesmo x. Verdadeiro: y menor. Falso: y maior.
- Dados dinâmicos: use ={{ $json.nome_campo }}
- Não inclua "credentials"

NÓS DISPONÍVEIS:
- (todos da V1, mais:)
- IF: n8n-nodes-base.if (v2)
- Switch: n8n-nodes-base.switch (v3)
- Merge: n8n-nodes-base.merge (v3)

APÓS O JSON, inclua obrigatoriamente:
1. Credenciais para configurar
2. O que ajustar (condição do IF, IDs reais)
3. Como importar: n8n → ícone de menu → Import from JSON

Nó de IA se liga de um jeito diferente

Pedido V3 · com Basic LLM Chain ou AI Agent 
Você é um especialista em n8n, plataforma de automação low-code.
Seu objetivo é me ajudar a criar um workflow que usa IA para gerar, classificar

AVISO IMPORTANTE: Nós de IA têm uma estrutura especial de conexão diferente de nós comuns.
Siga o template abaixo à risca — não altere o formato das connections de IA.

REGRA PRINCIPAL: Não gere o JSON ainda. Faça uma entrevista comigo primeiro.
Faça UMA pergunta por vez. Só gere o JSON quando eu disser "pode gerar".

--- ENTREVISTA ---

1. "O que este workflow precisa fazer? Descreva em 1 ou 2 frases."
2. "Como este workflow começa?
   (A) Formulário  (B) Agendamento  (C) Webhook  (D) Manual  (E) Outro"
3. "Quais informações chegam no início?"

Siga exatamente este modelo:

      "name": "Gemini Flash",

      "name": "Envia Resultado",
      "type": "n8n-nodes-base.gmail",
      "typeVersion": 2.1,
      "position": [840, 300],
      "parameters": {
        "resource": "message",
        "operation": "send",
        "sendTo": "email@exemplo.com",
        "subject": "Resultado da IA",
        "message": "={{ $json.text }}",
        "emailType": "text"
      }
    }
  ],
  "connections": {
    "Início": {
      "main": [[{"node": "Gera Texto com IA", "type": "main", "index": 0}]]
    },
    "Gemini Flash": {

    },

  },

REGRAS CRÍTICAS:
- O Gemini aparece nas connections como ORIGEM, apontando para o LLM Chain com tipo "ai_languageModel"
- O output do LLM Chain chega no campo "text" do próximo nó: use $json.text para acessá-lo
- position: o Gemini fica 200px abaixo do LLM Chain (mesmo x, y + 200)
- Não inclua "credentials"

NÓS DISPONÍVEIS:
- (todos da V1, mais:)
- Basic LLM Chain: @n8n/n8n-nodes-langchain.chainLlm (v1.4)
- Google Gemini: @n8n/n8n-nodes-langchain.lmChatGoogleGemini (v1)
- AI Agent: @n8n/n8n-nodes-langchain.agent (v1.7)

APÓS O JSON, inclua obrigatoriamente:
1. Credenciais para configurar (Gemini precisa de Google AI Studio API key)
2. O que ajustar (prompt da IA, campo referenciado, IDs reais)
3. Como importar: n8n → ícone de menu → Import from JSON

Os nomes de nó e as versões dentro dos três pedidos são do material, de abril de 2026. Eles envelhecem: é exatamente o erro nº 4 da aula 5 do B11. Se a importação recusar por versão, confira na tela do seu n8n qual é a atual e corrija no pedido antes de gerar de novo.

05
A sua vez

Importar e ajustar

1
Importar
  1. Copie o JSON que a IA gerou.
  2. No n8n, clique no ícone de menu, no canto do canvas.
  3. Selecione Import from JSON.
  4. Cole e confirme.
Deu certo quando

O canvas aparece com os nós conectados. Os avisos de credencial são esperados, e não são erro.

2
Ajustar o que é seu
  • Credenciais: a IA nunca tem acesso às suas chaves. Conecte no n8n depois de importar.
  • Identificadores reais: planilhas, pastas, documentos. Ela usa exemplos; substitua pelos seus.
  • Expressões: $json.campo pode vir com o nome errado. Confira na primeira execução.
  • No V3: se o modelo não aparecer conectado ao nó de IA no canvas, conecte à mão.
Se travar sem saber por onde começar a revisar

Comece de trás para frente: abra o último nó, veja de quais campos ele depende, e vá subindo conferindo se cada um existe no nó anterior. É mais rápido que ler o fluxo do começo, porque o que interessa é o que chega no fim.

Não vale: ativar e ver no que dá. Fluxo gerado por IA em produção sem revisão é como o material diz: vai para o ar com defeito, e você descobre pelo destinatário.
Deu certo quando

Você rodou um teste manual com 1 caso real antes de ativar, e conferiu o resultado de cada nó.

06
A cerca

Pegadinhas

Usar a V1 num fluxo com IF

O formato das conexões sai errado, e o fluxo importa sem funcionar. Escolha a versão pelo tipo do fluxo, não pelo tamanho.

Confiar nas expressões sem testar

Um $json.campo pode estar com nome errado, e isso não dá erro de importação: dá resultado vazio na execução.

Importar sem revisar

Se a IA inventou um campo, o erro aparece só quando o fluxo rodar, e com gente esperando do outro lado.

Esperar que funcione de primeira

Os ajustes são a parte normal do trabalho, não sinal de que o pedido estava ruim.
