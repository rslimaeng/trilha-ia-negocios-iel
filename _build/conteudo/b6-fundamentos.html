Mapa de Capacidades · B6

Marque com honestidade ao final do bloco. Se algum item ainda não estiver ✅, volte e revise antes de seguir pra B7.

  • Navego no canvas (adicionar nó, conectar, executar) sem hesitar.
  • Renomeio cada nó antes de configurar (com emoji + ação concisa).
  • Pino dados de saída de um nó (tecla P) e despino quando termino o teste.
  • Identifico o que é trigger, nó de ação e conexão num workflow.
  • Leio o output em Schema / Table / JSON e sei quando usar cada visão.
  • Vejo uma expression {{ ... }} se formando sozinha quando arrasto um campo (sem precisar entender a sintaxe ainda).
  • Vejo um AI Agent simples respondendo no chat e entendo que vou destrinchar isso no B10.
03
Confira

Protocolo de Validação: fluxos do B6

Antes de declarar que seu fluxo "tá funcionando":
  1. Executou sem erro: nenhum nó vermelho no painel de execuções.
  2. Output no formato esperado: abra o nó, vá em Output, confirme em Schema/Table/JSON que os campos estão lá.
  3. Caso de borda mínimo testado: se for o agente da aula 5, mude o System Message e veja a resposta mudar. Se for o Set da aula 4, troque um campo de String pra Number e veja o comportamento.

Próximo bloco: B7, Gatilhos. Você vai aprender os outros jeitos de iniciar um workflow (Schedule, Webhook, Form, App Event).
