01
O que você vai aprender

Por que isso importa

Em uma frase

A maioria dos workflows que se chamam "AI" no Instagram são só um nó OpenAI no meio. Isso não é AI Agent.

Entender a diferença é o que separa quem vende automação genérica de quem entrega valor real. Tem mais: quem coloca tudo no AI Agent paga mais (loop de raciocínio = mais tokens) e demora mais. Os fluxos certos usam o nó certo, e na maioria dos casos, o nó certo não é o AI Agent.

O "3x mais" do topo é afirmação do material, de abril de 2026, sem fonte declarada; entra como está.

03
Como funciona

AI Agent vs Basic LLM Chain: a comparação que mais importa

Os dois nós mais usados são AI Agent e Basic LLM Chain. Confundir os dois é o erro mais frequente, e mais caro.

Basic LLM ChainAI Agent
Ferramentas externasNãoSim (Sheets, Telegram, Drive, qualquer nó)
Decide próximo passoNãoSim: pode chamar tool, ler resultado, decidir de novo
Ideal praAvaliar / classificar / resumir texto que já chegouLer dados, enviar mensagens, agir em sistemas

Exemplos práticos de quando usar cada um

04
A demonstração

Como funciona na prática: escolhendo na hora

Antes de arrastar AI Agent pro canvas, faça 3 perguntas
  1. O fluxo precisa que a IA chame ferramentas externas? Se não → Basic LLM Chain ou nó especializado.
  2. O fluxo é uma conversa multi-turno? Se sim → provavelmente AI Agent (precisa de memória).
  3. A IA só precisa transformar texto que já chegou? Se sim → Basic LLM Chain ou nó especializado.
Iniciante coloca tudo no AI Agent

Profissional escolhe o nó certo pra cada tarefa. Custo, performance e clareza melhoram.

05
A cerca

Pegadinhas

Achar que toda automação com IA precisa ser Agent

Não. Pra resumir/classificar/extrair, outro nó é mais barato e mais rápido.

Usar AI Agent sem definir tools

Vira chat genérico que finge fazer coisas. "Vou agendar pra você" → não agenda. Sem tool = sem ação.

Usar Basic LLM Chain quando precisaria de memória

Cada execução vira "primeira mensagem". Sintoma: agente esquece nome dito 2 mensagens atrás.

Custo escondido do AI Agent

Cada chamada de tool é uma volta no loop. 1 input → 4 chamadas de LLM se ele decide chamar 3 tools. Barato em testes, perceptível em volume.
