01
O que você vai aprender

Por que isso importa

Em uma frase

Expression é sempre a escolha certa quando o valor depende do que entrou no fluxo: Fixed só pra valor que nunca muda.

Sem expressions, todo workflow que você construir é estático: copia tutorial, troca um valor, roda uma vez. Com expressions, você lê dados que vieram do trigger ou de outro nó e monta saídas dinâmicas. Essa é a diferença entre quem segue receita e quem cria automação.

02
O conceito, e é um só

Conceito central

O conceito desta aula

Todo campo de configuração no n8n tem dois modos: Fixed e Expression

ModoO que éQuando usar
ExpressionValor dinâmico lido dos dadosTudo que muda por execução (nome, e-mail, valor, status)

A linha do modo Fixed não veio no export do Notion; a tabela está como chegou. Pelo texto da seção 01: Fixed é o valor que nunca muda.

Como ativar Expression: clique no ícone de raio ao lado do campo. O fundo do campo fica roxo.

Analogia

A Expression é um crachá dinâmico: em vez de escrever um nome fixo, você diz ao robô "vá no pacote anterior, leia a etiqueta 'Nome' e cole a resposta aqui". Foi assim que ela apareceu em sala.

  • O crachá escrito à mão = campo Fixed
  • O crachá que se preenche sozinho = campo Expression
  • A etiqueta lida = $json.nome

O crachá, em slide. O nome escrito no crachá é o do instrutor, que fez o exemplo em sala; no seu fluxo, a expression cola o seu.

Sintaxe: os 2 padrões que você vai usar 90% das vezes

PadrãoQuando usarExemplo
{{ $('NomeDoNó').item.json.campo }}Ler de um nó específico mais atrás{{ $('📦 Dados').item.json.email }}

A linha do primeiro padrão, {{ $json.campo }}, não veio no export do Notion; ele está traduzido logo abaixo.

Traduzindo:

  • $json = "o JSON que veio do nó anterior"
  • .nome = "a chave chamada nome dentro desse JSON"
  • $('NomeDoNó') = "vai lá no nó com esse nome específico"

Expressões úteis além de campos simples

ExpressionPra que serve

Boa notícia

Você não precisa decorar. Arrastar dado do painel de input pra um campo gera a Expression automaticamente. Você só precisa ler depois pra entender o que foi gerado.

03
Como funciona

Como funciona na prática

Hábito profissional: renomeie nós ANTES de configurar

Se você usa {{ $('Set').item.json.email }}, daqui a duas semanas você não sabe qual Set é esse. Mas se for {{ $('📦 Dados do Lead').item.json.email }}, fica óbvio. Renomear é hábito de minuto 1, não polimento de minuto 60.

Ciclo de uso

  1. Adicione o nó que precisa ler dado dinâmico.
  2. Clique no raio do campo pra ativar Expression mode.
  3. Arraste o campo do painel de input (à esquerda) pro campo da configuração: n8n gera a Expression sozinho.
  4. Execute o nó anterior antes (com Ctrl+Enter) pra ter dado real disponível.
  5. Pinne o output do nó anterior (P): assim você não precisa rodar tudo de novo a cada teste.
04
A demonstração

Exemplo guiado: micro-prática

Vamos construir 2 nós. O primeiro cria campos. O segundo lê esses campos com Expression.

Exemplo guiado · Dados de Teste e Leitura com Expression

Passo 1, preparar:

  1. Abra um workflow novo.
  2. Renomeie o Manual Trigger pra ▶️ Disparo Manual.

Passo 2, criar dado:

  1. Adicione um Edit Fields (Set). Renomeie pra 📦 Dados de Teste.
  2. Adicione 3 campos (Fixed): nome → (seu nome); cargo → (seu cargo); cidade → (sua cidade).
  3. Execute (Ctrl+Enter).
  4. Abra o JSON view do nó 📦 Dados de Teste. Confira que tem os 3 pares chave:valor.
  5. Pinne os dados (P): aparece um pino.

Passo 3, ler com Expression:

  1. Adicione um segundo Edit Fields. Renomeie pra 📤 Leitura com Expression.
  2. Adicione 1 campo: saudacao.
  3. Ative Expression (clique no raio). Fundo fica roxo.
  4. Digite:
O valor do campo saudacao 
Olá, {{ $json.nome }}! Você é {{ $json.cargo }} de {{ $json.cidade }}.
  1. Execute.
  2. Abra o JSON view deste nó. Você verá:
Output do 📤 Leitura com Expression (execução 435) 
{ "saudacao": "Olá, (seu nome)! Você é (seu cargo) de (sua cidade)." }

O momento em que {{ $json.nome }} vira o seu nome na tela é o instante de compreensão. A Expression não é uma string mágica: é uma instrução que diz: "abra o JSON do nó anterior, pegue a chave nome, cole aqui."

Variação rápida

Adicione um terceiro nó depois do 📤 Leitura com Expression. Use {{ $('📦 Dados de Teste').item.json.cargo }} pra ler direto do primeiro Set, pulando o intermediário. Confirma que dá pra alcançar qualquer nó pelo nome. No teste saiu "cargo_direto": "(seu cargo)".

05
A cerca

Pegadinhas

Esquecer das {{ }}

O n8n trata como texto literal. Se você digita $json.nome num campo Expression, ele bota a string $json.nome no output. Sempre {{ }}.

Misturar Fixed e Expression

Se o campo está em Fixed mode, a Expression não é interpretada. Ative o raio primeiro.

Tipo de dado errado

{{ $json.idade }} retorna string se a origem mandou "30" entre aspas. Comparações (> 18) podem falhar. Use {{ Number($json.idade) }}.

Renomeou o nó depois de criar a Expression

Se você tem $('Set').item.json.nome e renomeia o Set pra "Dados", a Expression quebra. Renomeie ANTES de configurar.

Tentar acessar campo inexistente

Retorna undefined. No JSON view, aparece como nada. Sempre confira o nome exato da chave no input.
