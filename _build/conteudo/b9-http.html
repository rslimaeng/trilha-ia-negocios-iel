Por que isso importa

Em uma frase

Todo sistema com API fala HTTP. Quem domina HTTP Request consegue conectar com qualquer coisa do mundo. Quem não domina fica refém de "tem nó nativo?".

O n8n já tem nós nativos pra Gmail, Sheets, Telegram, Drive e dezenas de outros serviços. Mas e quando o sistema é interno da sua empresa? Ou uma API menos conhecida?

Como o n8n responde

Toda chamada retorna 3 coisas: status code, headers de resposta, body. O n8n entrega o body como JSON automaticamente quando a API responde nesse formato.

CódigoSignificadoAção
200 OKTudo certoContinuar
201 CreatedCriado com sucesso (POST)Continuar
400 Bad RequestPedido malformadoConferir body/params
401 UnauthorizedCredencial errada/expiradaReconfigurar credencial
404 Not FoundURL não existeConferir URL
429 Too Many RequestsRate limit estouradoAdicionar Wait node
500 Internal Server ErrorProblema do outro ladoTentar de novo

03
Como funciona

Como funciona na prática

Configuração mínima de um GET

  1. Adicione um HTTP Request node. Renomeie pra algo descritivo (ex.: 🐶 Busca foto cachorro).
  2. Method: GET
  3. URL: https://dog.ceo/api/breeds/image/random
  4. (Se a API for pública, nenhuma autenticação necessária.)
  5. Execute. Output:
O output do GET 
{ "message": "https://images.dog.ceo/...jpg", "status": "success" }

Configuração de um POST com body JSON

  1. Method: POST
  2. URL: https://jsonplaceholder.typicode.com/posts
  3. Headers: ative Send Headers. Adicione Content-Type = application/json.
  4. Body: ative Send Body. Modo: JSON. Conteúdo:
O body do POST 
{
  "title": "Meu post",
  "body": "Conteúdo aqui",
  "userId": 1
}
  1. Execute. Resposta inclui o id do post criado.

Redesenho do canvas, a partir da execução de teste (execução 449, 16/09/2026). O POST acima, com o header e o body do texto, voltou { "title": "Meu post", "body": "Conteúdo aqui", "userId": 1, "id": 101 }: o id é o que a API criou. Conferido na tela: os campos se chamam Send Headers, Specify Headers ("Using Fields Below"), Send Body, Body Content Type (JSON) e Specify Body ("Using JSON").

Autenticação: os 3 padrões mais comuns

PadrãoComo configurar no n8n
API Key no headerHeaders → Authorization: Bearer SUA_KEY ou X-API-Key: SUA_KEY
API Key na queryQuery Params → ?api_key=SUA_KEY
OAuthUse a opção Generic Credential Type → OAuth2 API. Ver aula 3 (Credenciais)

Tabela remontada: três padrões que o export tinha espremido em duas linhas.

Boa prática

Nunca cole a API key direto na URL/header em modo Fixed. Crie uma credencial (menu Credentials → Header Auth) e referencie. Assim o segredo fica protegido.

Atalho mágico: Curl Import

Quase toda doc de API mostra um exemplo em curl (comando de terminal pra fazer chamada HTTP). O n8n importa esse texto e configura tudo automaticamente: método, URL, headers, body.

Os 5 passos do Import cURL 
1. Abra a doc da API (ex.: OpenWeather).
2. Encontre o exemplo curl. Algo como:
   curl "https://api.openweathermap.org/data/2.5/weather?q=Fortaleza&appid=SUA_KEY"
3. Copie a linha inteira.
4. No HTTP Request node, clique em "Import cURL" (canto superior direito).
5. Cole. Confira: URL, método, headers, query params já preenchidos.

Conferido na tela em 16/09/2026: o botão "Import cURL" está no canto superior direito do painel Parameters do nó, acima do campo Method.

Por que isso é ouro

Doc de API costuma ser longa, prolixa, em inglês técnico. Em vez de ler tudo e configurar campo por campo, você cola o curl da seção "exemplo" e o n8n faz o resto. Atalho que economiza horas.

A varinha, em slide. O painel desenhado à direita é o mesmo que abre quando você clica em Import cURL.

05
A cerca

Pegadinhas

Não setar Content-Type quando manda JSON

API recebe como texto, não interpreta. Sempre Content-Type: application/json em POST/PUT com body JSON.

Confundir Query Params com Body

Query vai na URL (?nome=(seu nome)), Body vai separado. APIs documentam qual usar.

API key colada em texto fixo

Vaza ao exportar workflow. Sempre via Credenciais.

401 ≠ 404 ≠ 500

Leia o código antes de mexer. 401 é credencial, 404 é URL, 500 é problema do outro lado (e geralmente passa sozinho).

Rate limit (429) silencioso

Algumas APIs limitam X requisições por minuto. Em loop com volume, adicione Loop Over Items + Wait.

Resposta não-JSON

Algumas APIs retornam XML, HTML, texto puro. Verificar Content-Type da resposta antes de assumir JSON.
