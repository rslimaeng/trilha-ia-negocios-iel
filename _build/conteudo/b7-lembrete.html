Por que isso importa

Em uma frase

Juntar 1 trigger (Schedule) com uma entrega real (Gmail ou Telegram) e ter um fluxo rodando sozinho amanhã de manhã: sem precisar você clicar.

Você acabou de ver os 5 tipos de trigger. Agora vamos juntar 1 deles com uma entrega real e ver o fluxo disparar sem você.

03
Como funciona

Passo a passo

Pré-requisitos
  • B6 e aulas 1-5 do B7 concluídos.
  • Credencial do Gmail OAuth configurada no n8n (ou bot do Telegram).
  • 1 dia pra ver chegar pela primeira vez.

As três colunas do slide são os passos 2, 3 e 4 abaixo. O que o slide resume em "escolha Dias Úteis", o passo 2 escreve por extenso: é o cron.

1
Crie o workflow
  1. Workflows → + Add workflow.
  2. Renomeie pra Lembrete Diário Foco.
2
Schedule Trigger (todo dia útil 8h)
  1. Adicione Schedule Trigger → renomeie pra 📅 Toda Manhã 8h.
  2. Configure (modo Cron, mais flexível):
Trigger Interval: Custom (Cron) · Expression 
0 8 * * 1-5

(8h, segunda a sexta)

  1. Alternativa (modo simples sem cron):
    • Trigger Interval: days
    • Days Interval: 1
    • Trigger At Hour: 8
    • (Vai disparar todo dia, inclusive sábado/domingo. Pra excluir fim de semana, use cron mesmo.)
3
Set node (compor mensagem)
  1. Adicione Edit Fields (Set) → renomeie pra 📦 Compor Mensagem.
  2. Configure: Mode Manual Mapping; Add Field: Name mensagem (String); Value:
O valor do campo mensagem 
☀️ Bom dia! Hoje é {{ $now.toFormat('cccc, dd LLL') }}. Foco do dia: ___
  1. Pinne o output (P) pra reutilizar em testes sem disparar Schedule.
4
Gmail Send (entregar)
  1. Adicione Gmail → operation: Send Message → renomeie pra 📧 Enviar Lembrete.
  2. Conecte sua credencial Gmail (se ainda não tem, configure agora).
  3. Configure:
    • To: seu próprio e-mail
    • Subject: Foco do dia
    • Message: arraste o campo mensagem do painel esquerdo (vai virar {{ $json.mensagem }})
5
Salvar, ativar, testar
  1. Salve (Ctrl + S ou auto).
  2. Ative o workflow (toggle "Active" no canto superior direito).
  3. Pra testar agora sem esperar 8h:
    • Clique em Execute Workflow (canto superior direito).
    • Roda 1 vez ignorando o schedule.
    • Confira que o e-mail chegou.
  4. Amanhã às 8h, o e-mail real deve chegar automaticamente.
O que esperar
  • ✅ E-mail chegando às 8h (horário do servidor, geralmente UTC) com a mensagem montada.
  • ✅ A data muda automaticamente a cada dia ({{ $now }}).
❌ Se não chegou

Workflow não foi ativado. Volta no n8n e confere o toggle.

Não vale: chutar o cron. Cron mal escrito → roda 23h em vez de 8h. Use crontab.guru. Não chuta cron.

Variações pra exercitar

6
Variação 1: trocar Gmail por Telegram
  1. Crie um bot Telegram (BotFather no Telegram).
  2. Adicione Telegram → operation: Send Message.
  3. Conecte credencial do bot.
  4. Chat ID: seu próprio chat (descubra abrindo @userinfobot no Telegram).
  5. Text: {{ $json.mensagem }}
  6. Substitua o nó Gmail pelo Telegram. Pronto.

Não rodada no teste de 16/09: a conta de teste não tem bot do Telegram. O caminho é o do Notion, como está.

7
Variação 2: mensagem com dia da semana customizado

Mude o Set pra:

O valor do campo mensagem · variação 2 
{{ ['😴 Segunda', '💪 Terça', '🚀 Quarta', '⚡ Quinta', '🍻 Sexta'][$now.weekday - 1] }}! Foco do dia: ___

Cada dia ganha emoji + tom diferente.

Rodada no teste de 16/09, uma quarta

Saiu 🚀 Quarta! Foco do dia: ___ (execução 406). A lista tem cinco posições, de segunda a sexta, e o cron do passo 2 só dispara nesses dias.

8
Variação 3: foco do dia vindo de uma planilha
  1. Tenha uma planilha "Focos da Semana" com colunas dia_semana e foco.
  2. Antes do Set, adicione Google Sheets → Get Rows.
  3. Filtre pra dia atual.
  4. No Set, use {{ $('Google Sheets').item.json.foco }} no campo mensagem.
  5. Agora você atualiza só a planilha: o e-mail puxa sozinho.

Não rodada no teste de 16/09: depende de uma planilha sua. É a ponte pro B9, onde o Sheets entra de verdade.

06
A cerca

Pegadinhas

Workflow não ativado → não dispara em produção

Pegadinha #1. Ative o toggle.

Fuso horário UTC vs local

O n8n por padrão usa UTC (Brasília = UTC-3). Se você quer 8h Brasília, configura 11 UTC ou ative Use workflow timezone nas Settings.

Esquecer de pinar dados

Cada teste roda o Schedule + Set + Gmail. Pinar o Set economiza testes desnecessários.

Credencial Gmail expirando

Se o e-mail parou de chegar depois de semanas, vá em Credentials e refaça o OAuth.
