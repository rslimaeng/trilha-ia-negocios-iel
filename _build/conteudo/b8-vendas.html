O conceito desta aula

Oito nós, de uma planilha a um e-mail: Manual → Sheets → Set → Summarize → Sort → Aggregate → Set → Gmail

  • Gatilho: Manual (depois Schedule pra rodar toda segunda 8h).
  • Execução: Sheets → Set (limpar tipos) → Summarize (agrupar e somar) → Sort → Aggregate → Set (formatar texto).
  • Entrega: Gmail com resumo: "Casa: R$ 12.450 (8 pedidos)" linha por linha, ordenado do maior pro menor.

A fábrica, como foi mostrada em sala. O slide tem seis máquinas; o passo a passo abaixo tem oito nós, porque o gatilho e o Set que monta o texto aparecem separados.

Pré-requisitos
  • Planilha "Pedidos 2026" no Google Drive com colunas: data | categoria | produto | valor | vendedor e ao menos 30 linhas variadas.
  • Credencial Google Sheets configurada no n8n.
  • Credencial Gmail configurada no n8n.
  • Aulas anteriores do B8 (especialmente Set, Expressions e Listas).

Gere um arquivo CSV chamado "pedidos-2026.csv" com 40 linhas representando pedidos
fictícios de um e-commerce brasileiro pequeno. Use ponto e vírgula (;) como

alguns baixos), datas espalhadas pelos 30 dias do mês. Não inclua linhas em

03
Como funciona

Passo a passo

1
Manual Trigger

Adicione, renomeie pra ▶️ Disparo. Depois você troca por Schedule.

2
Google Sheets: Get Rows
  • Resource: Sheet Within Document
  • Operation: Get Row(s) in Sheet
  • Document: selecione Pedidos 2026
  • Sheet: Pedidos
  • Renomeie: 📋 Lê Pedidos

Execute. Cada linha vira 1 item. Pinne este nó (P) pra não reler a planilha a cada teste.

3
Set: limpar tipos

A planilha entrega valor como string. Pra somar, precisa virar number (revisar aula 1).

  • Adicione Edit Fields (Set), renomeie 🧹 Limpa Tipos.
  • Mode: Manual Mapping
  • Include Other Fields: ligado
  • Adicione 1 campo: Name valor; Type Number; Value (Expression) {{ Number($json.valor) }}

Execute. No JSON: valor aparece sem aspas.

4
Summarize: agrupar e somar

O nó-coração da análise. Agrupa por uma chave e calcula soma/média/contagem.

  • Adicione Summarize, renomeie 📊 Resumo por Categoria.
  • Fields to Summarize: Field valor, Aggregation Sum; Field produto, Aggregation Count
  • Fields to Split By: categoria

Execute. Saída: N itens (1 por categoria) com categoria, sum_valor, count_produto.

Pra copiar 
[
  { "categoria": "Casa",        "sum_valor": 12450, "count_produto": 8 },
  { "categoria": "Eletrônicos", "sum_valor": 23890, "count_produto": 5 }
]
Por que Summarize e não Aggregate?

Aggregate empacota tudo em arrays sem fazer matemática. Summarize faz agrupamento + cálculo num passo só. Você usa os dois juntos logo abaixo.

5
Sort: decrescente
  • Adicione Sort, renomeie ⬇️ Ordena Maior pro Menor.
  • Type: Simple
  • Fields To Sort By: sum_valor, Order: Descending
6
Aggregate: juntar tudo num item só

Pra mandar 1 e-mail com tudo, empacote as N linhas num item único.

  • Aggregate → 🛍️ Empacota.
  • Aggregate: All Item Data (Into a Single List)
  • Put Output in Field: linhas

Execute. Saída: 1 item com linhas: [...todas as categorias...].

7
Set: montar texto do e-mail
  • Edit Fields (Set) → 📝 Monta Texto.
  • Include Other Fields: desligado
  • 1 campo: Name corpo; Type String; Value (Expression):
O valor do campo corpo · cole como está 
Resumo de vendas — semana de {{ $now.toFormat('dd/MM/yyyy') }}

{{ $json.linhas.map(l => `${l.categoria}: R$ ${l.sum_valor.toFixed(2)} (${l.count_produto} pedidos)`).join('\n') }}

Total geral: R$ {{ $json.linhas.reduce((acc, l) => acc + l.sum_valor, 0).toFixed(2) }}
Calma com a Expression aqui

3 truques: .map() percorre o array montando cada linha; .join('\n') cola as linhas com quebras; .reduce() soma o total geral. Você não precisa decorar: cole, execute, leia o output e identifique cada parte. Se der erro, abra o JSON view do nó anterior pra conferir os nomes dos campos (sum_valor, count_produto).

8
Gmail: enviar
  • Gmail → 📧 Envia Resumo.
  • Resource: Message, Operation: Send
  • To: seu e-mail
  • Subject: Resumo de vendas — {{ $now.toFormat('dd/MM/yyyy') }}
  • Email Type: Text
  • Message: {{ $json.corpo }}

Execute. Confira a caixa de entrada.

Protocolo de Validação

Antes de considerar o fluxo "pronto":

  1. Sem nó vermelho: todos executaram em verde.
  2. Output esperado: e-mail chegou com categorias ordenadas do maior pro menor, valores com 2 casas decimais, total geral conferindo com a soma manual.
  3. Caso de borda: duplique uma linha da planilha (mesmo produto, mesma categoria) e rode de novo. count_produto deve aumentar em 1, sum_valor deve refletir.
Se o total saiu absurdo, tipo "125200" em vez de 325

valor como string. Sem o Set convertendo, o Summarize soma como texto ("125" + "200" = "125200"). Confira o JSON view do 🧹 Limpa Tipos.

Não vale: pular o passo 3 e "arredondar" o resultado na mão no e-mail. O erro está antes do Summarize, e a correção também.

Variações pra praticar

  • Trocar categoria por vendedor no Summarize → ranking de vendedores da semana.
  • Filtrar últimos 7 dias: Filter antes do Summarize, com a condição:
    Pra copiar 
    {{ new Date($json.data) >= $now.minus({days: 7}).toJSDate() }}
  • Trocar Manual por Schedule: toda segunda 8h. Vira relatório automático.
  • Trocar Gmail por Telegram: mesma lógica, outra entrega.

Nenhuma das quatro rodou no teste de 16/09: são a sua parte.

Mapa de Capacidades · checkpoint B8
  • Configurei Sheets Get Rows pra ler uma planilha.
  • Converti valor de string pra number com Set + Number().
  • Configurei Summarize agrupando por categoria, somando valor e contando pedidos.
  • Ordenei com Sort decrescente e empacotei com Aggregate.
  • Montei o texto do e-mail com .map().join() e .reduce().
  • Enviei o resumo no Gmail e validei nos 3 pontos do protocolo.
