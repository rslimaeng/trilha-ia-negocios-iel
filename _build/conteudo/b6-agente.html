03
Como funciona

Passo a passo

Pré-requisitos
  • Conta n8n Cloud com OpenAI credential configurada (o instrutor vai compartilhar como criar).
  • Aulas 1-4 do B6 concluídas.
  • Link de locais para pegar modelos gratuitos: console.groq.com, openrouter.ai, aistudio.google.com.
As duas portas gratuitas, conferidas em 16/09/2026

Decisão de 14/09 para esta turma: nada de chave paga. Google AI Studio (aistudio.google.com) é a porta principal: a página de preços do Gemini mostra um Free Tier "free of charge" pro Gemini 3.8 Flash. No n8n, o sub-nó é o Google Gemini Chat Model, e a credencial é a chave do AI Studio. OpenRouter (openrouter.ai) é a alternativa: 20 dos 444 modelos listados hoje são :free. Se usar OpenAI, como o Notion descreve, a chave é paga.

1
Crie o workflow
  1. Workflows → + Add workflow.
  2. Renomeie pra Meu primeiro AI Agent.
2
Adicione o Chat Trigger
  1. Clique duplo no canvas → busque "Chat Trigger" (chat embutido do n8n, não confundir com Telegram).
  2. Adicione. Renomeie pra 💬 Chat Trigger.
  3. Não precisa configurar nada: vem pronto.
3
Adicione o AI Agent
  1. Conecte um novo nó depois do Chat Trigger → busque "AI Agent" → adicione.
  2. Renomeie pra 🧠 AI Agent.
  3. Abra o nó. Você vê: campo System Message (vazio), campo User Message (já vem com {{ $json.chatInput }}, ótimo, deixa assim).
Conferido em 16/09/2026: o emoji no nome do AI Agent quebra o nó

Na versão atual do n8n, o nó AI Agent (3.1) grava a resposta com uma chave feita do próprio nome, e ela só aceita letras, números e _. Com o nome 🧠 AI Agent a execução para com o erro Custom date key can only contain characters "A-Za-z0-9_". Nomeie esse nó sem emoji: AI Agent. Os outros nós (Chat Trigger, Set, Gmail) aceitam o emoji normalmente.

4
Configure o Chat Model
  1. Embaixo do AI Agent, na porta Chat Model, clique no +.
  2. Selecione OpenAI Chat Model.
  3. Em Credential, conecte sua chave OpenAI.
  4. Em Model, selecione gpt-4o-mini.
  5. Feche o sub-nó.
Pela porta gratuita, o mesmo passo fica assim

Selecione Google Gemini Chat Model; em Credential, conecte a chave do AI Studio; em Model, um Flash do free tier. No teste de 16/09 foi gemini-3.5-flash: o padrão que o nó sugere, gemini-2.5-flash, ficou "rodando" sem responder.

5
Teste
  1. Em cima, clique em Open Chat (botão que aparece quando o Chat Trigger é o gatilho).
  2. Mande qualquer coisa: "oi, tudo bem?".
  3. O agente responde. Pode demorar 2-3 segundos: o LLM tá pensando.
  4. Mande: "qual é a capital do Brasil?". Responde Brasília.
  5. Mande: "e a do Ceará?". Provavelmente ele não lembra que você falou de Brasil, porque a gente não configurou memória. É proposital.
O que deve acontecer nas três mensagens
  • "oi, tudo bem?": uma resposta qualquer, educada.
  • "qual é a capital do Brasil?": Brasília.
  • "e a do Ceará?": ele não sabe do que você está falando. Sem memória, cada mensagem é independente.
Se a execução deu erro 401

Esquecer de configurar a credencial do modelo dá erro 401. Voltar em Credentials, conectar a chave.

Não vale: esperar que ele faça ações ("agende uma reunião"). Sem ferramentas, ele só conversa. Promete e não cumpre. Pra agir, precisa de Tools: B10.

Exemplo guiado · o canvas e a conversa

6
Variação 1: adicione personalidade

No AI Agent, em System Message, escreva:

System Message · variação 1 
Você responde sempre em português brasileiro, com tom descontraído e bem-humorado.
Use no máximo 2 frases.

Teste de novo. A diferença é imediata.

Rodada no teste de 16/09 (execução 412)

"oi, tudo bem?" virou: "Opa, tudo ótimo por aqui! Tirando a parte em que eu ainda não ganhei na loteria, o resto tá uma beleza." Duas frases, tom descontraído.

7
Variação 2: restrinja o escopo

Mude o System Message pra:

System Message · variação 2 
Você é um assistente especializado em automação com n8n.
Se a pergunta não for sobre n8n, automação ou IA, responda educadamente que esse não é seu tema.
Sempre responda em português.

Pergunte algo fora do tema (ex.: "qual a receita de bolo de cenoura?"). Ele recusa.

Rodada no teste de 16/09 (execução 414)

Você acabou de fazer a primeira instrução real de System Prompt. Isso é o que o B10 vai aprofundar: como escrever instruções que fazem o agente se comportar do jeito que você precisa. Por enquanto, basta ver que funcionou. No teste de 16/09 (execução 414), a receita de bolo voltou assim: "Como sou um assistente especializado em n8n, automação e inteligência artificial, não consigo te ajudar com receitas de cozinha."

O que esta aula NÃO te ensinou (e está tudo bem)
  • Como o agente decide quando usar uma ferramenta. → B10 / aula 2
  • Como dar memória ao agente pra ele lembrar do que você disse. → B10 / aula 5
  • Como conectar Calendar / Gmail / Sheets pra ele agir no mundo real. → B10 / aula 4
  • Como escrever System Prompt em produção. → B10 / aula 3
Por que dar esse "gostinho" agora?

Porque o resto do módulo vai parecer mais concreto sabendo pra onde aponta. Cada nó que você vai aprender (Set, IF, HTTP Request) vai virar uma peça que o agente vai usar lá no B10.
