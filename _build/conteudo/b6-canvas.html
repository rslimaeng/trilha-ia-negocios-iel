Em uma frase

Você já abriu um sistema novo no trabalho e ficou parado olhando pra tela alguns minutos sem saber onde fica o quê? A interface do n8n parece assim no primeiro minuto, e faz sentido total no décimo.

Os dois hábitos desta aula (renomear nó antes de configurar e pinar dados depois de cada execução boa) parecem detalhe, mas mudam a relação com a ferramenta.

Quem não conhece a interface gasta 30% do tempo procurando botão. Mas o ganho real desta aula não é só atalho de teclado: é entender que o canvas é seu ambiente de trabalho diário e que dois hábitos pequenos (nomear e pinar) transformam workflows ilegíveis em workflows que você consegue manter daqui a um mês.

O conceito, e é um só

Conceito central

O conceito desta aula

A tela do n8n tem 4 espaços

01

Canvas

Onde os nós ficam. Espaço infinito; zoom com Ctrl + roda ou Ctrl + +/-.

02

Painel lateral de nós

Biblioteca pra arrastar. Atalho: clique duplo no canvas (ou Tab) abre busca rápida.

03

Painel de configuração do nó

Abre quando você clica num nó. Tem 3 abas: Parameters (configuração), Settings (notas, retry, modo), Docs (documentação inline).

04

Painel de execuções

Histórico do que rodou (sucesso, erro, tempo): menu lateral → Executions.

Os quatro espaços no lugar em que ficam. O 3 só aparece quando você clica num nó; o 4 é um menu, não uma área do canvas.

Menus principais (lateral esquerda)

MenuPra que serve
WorkflowsLista de workflows do projeto
CredentialsAcessos a serviços externos (Gmail, Sheets, OpenAI)
ExecutionsHistórico de cada vez que algum workflow rodou
TemplatesWorkflows prontos pra adaptar
VariablesValores reutilizáveis entre workflows (plano pago)

Dois hábitos profissionais que mudam tudo

1. Renomeie o nó antes de configurar

Quando você usa Expression como {{ $('Set').item.json.email }}, daqui a 2 semanas você não sabe qual Set é esse. Mas se for {{ $('📦 Dados do Lead').item.json.email }}, fica óbvio.

Convenção sugerida: emoji + ação concisa.

PadrãoExemplos
Triggers▶️ Disparo Manual · 📅 Cron Diário · 📲 Telegram Trigger
Lógica❓ Score qualifica? · 🔀 Roteia por categoria
Dados📦 Dados do Lead · 🧹 Normaliza nome
Saída📧 Envia confirmação · 💾 Registra no Sheets
IA🤖 AI Extrai Agenda · 🧠 AI Agent Qualificador
Hábito

Renomeie no minuto 1, não no minuto 60. Workflow com 10 nós sem nome é workflow que você vai abandonar em 2 semanas.

2. Pinne os dados depois de cada execução boa

Quando o nó executa com sucesso, pressione P com ele selecionado. Aparece um pino no canto. A partir daí, mesmo que o trigger seja Webhook, Telegram ou qualquer coisa "ao vivo", o n8n usa o dado pinado nas próximas execuções de teste: sem precisar reenviar mensagem ou disparar evento real.

Por que importa:

  • Você economiza tempo de "reenviar dados" a cada teste.
  • Você economiza chamada paga (OpenAI cobra por execução).
  • Você consegue iterar nos nós seguintes mantendo o input estável.
Lembre de despinar (P de novo)

Quando terminar de testar: pinned data antigo em produção é fonte de bug silencioso.

Os dois hábitos, como foram mostrados em sala. O exemplo do cartão 1 é a convenção da tabela acima: emoji + ação.

04
A demonstração

Exemplo guiado: tour completo

Exemplo guiado · onze passos pela tela
  1. Abra um workflow vazio.
  2. Clique duplo no canvas → busque "Manual Trigger" → adicione.
  3. Renomeie pra ▶️ Disparo Manual.
  4. Adicione um Set (Edit Fields). Renomeie pra 📦 Dados de Teste.
  5. Adicione 2 campos: nome = "(seu nome)", cargo = "(seu cargo)".
  6. Conecte os nós (clique no ponto de saída do trigger e arraste pro Set).
  7. Execute (Ctrl+Enter).
  8. Clique no nó 📦 Dados de Teste → painel da direita → Output → JSON view. Confira os 2 campos.
  9. Pinne (P): o pino aparece.
  10. Vá no menu lateral → Executions. Veja o registro da execução que você acabou de fazer.
  11. Volte pro workflow, clique no ▶️ Disparo Manual, abra o painel: aba Settings. Olhe as opções de Notes, Retry, Continue On Fail. Não mexa, só identifique.

É o mesmo fluxo da aula 2, redesenhado da execução de teste (execução 407, 16/09/2026). O que muda nesta aula não é o fluxo: é o caminho pela tela até ele, e o pino no fim.

05
A cerca

Pegadinhas

Não saber que Tab abre busca de nós

Gasta 30 segundos pra cada nó procurando no painel lateral. Atalho economiza horas.

Confundir "execução de teste" com "ativação"

Clicar em Test workflow roda uma vez. Activate (toggle no canto superior direito) coloca o trigger pra escutar continuamente. Workflow desativado não roda em Webhook/Schedule.

Não pinar dados

Cada teste re-executa tudo desde o trigger, gastando tempo e (se tiver OpenAI no meio) dinheiro.

Renomear depois de criar Expressions

Expressions usam o nome do nó. Se você renomeia depois, todas as Expressions que apontam pro nome antigo quebram. Renomeie antes.

Esquecer pinned data despinado em produção

Pino ativo em workflow ativado faz ele rodar com dado fixo, ignorando o trigger real. Sintoma: ativou e parece "rodar" mas processa sempre os mesmos dados.
