Conceito central

O conceito desta aula

O que é uma tool

Uma tool é um nó (Sheets, Gmail, HTTP Request, etc.) que você conecta na porta lateral "Tool" do AI Agent. Quando conectado:

  • O nó deixa de rodar automaticamente no fluxo principal.
  • Vira uma opção que o agente pode chamar se decidir que precisa.
  • O agente decide quando usar lendo a descrição que você escreveu.

Como o agente "vê" a tool

Cada tool tem 3 informações que o LLM lê pra decidir:

  • Nome: identificador curto e claro (get_contact, send_email).
  • Descrição: quando o agente deve usar essa tool, em linguagem natural.
  • Parâmetros: quais dados a tool precisa (com $fromAI() pra cada).

A regra de ouro: nome + descrição claros

Ruim 
nome: tool1
descrição: faz coisas
Bom 
nome: get_contact
descrição: Busca contato no Google Contacts pelo nome ou e-mail.
Use SEMPRE que o usuário mencionar uma pessoa pelo nome
e você precisar do e-mail dela pra continuar.
Mantra: descrição de tool é prompt

Cada tool é uma mini-instrução que o agente lê. Vaga = uso errado. Específica = uso certo.

O $fromAI(): como o agente preenche os parâmetros

Quando uma tool precisa de dados (ex.: o e-mail do contato), você não preenche manualmente. Você usa $fromAI('nome_do_campo'): o LLM decide o valor na hora.

Exemplo na tool Gmail Send:

Os três campos da tool Gmail Send 
To:      {{ $fromAI('email') }}
Subject: {{ $fromAI('assunto') }}
Body:    {{ $fromAI('corpo') }}

O agente, ao ler a mensagem do usuário, infere o que vai em cada campo e preenche.

03
Como funciona

Como funciona na prática: adicionando uma tool em 4 passos

  1. Arrasta o nó (ex.: Google Sheets) na porta "Tool" do AI Agent.
  2. Configura o nó normalmente. Cada parâmetro variável vira $fromAI('campo').
  3. Renomeia com nome curto (get_contact, não Sheets1).
  4. Escreve a descrição no campo Tool Description. Inclua: o que faz, quando usar, quando NÃO usar.
Anti-padrão: 5 tools de uma vez

Cada tool nova aumenta a chance de o agente confundir quando usar. Adicione 1, teste, adicione a próxima.

04
A demonstração

Exemplo guiado: agente com 1 tool de Sheets

Exemplo guiado · "qual o orçamento do João?"

Agente lê uma planilha de leads e responde "qual o orçamento do João?".

  1. Setup base: Chat Trigger → AI Agent (Chat Model + Simple Memory).
  2. Arrasta Google Sheets na porta Tool. Renomeia: buscar_lead.
  3. Operation: Get Rows. Filter: nome Contains {{ $fromAI('nome_do_lead') }}.
  4. Tool Description:
Tool Description do buscar_lead 
Busca informações de um lead na planilha pelo nome.
USE sempre que o usuário perguntar dado de um lead específico.
NÃO USE se o usuário pedir "lista de leads" — nesse caso
responda que essa funcionalidade ainda não existe.
  1. System Prompt:
System Prompt do agente de leads 
ROLE: Assistente de consulta de leads.
TOOLS: buscar_lead.
RULES:
1. SEMPRE chame buscar_lead antes de responder sobre lead específico.
2. NUNCA invente dado. Se não encontrar, diga "Lead não encontrado".
  1. Teste: "Qual o orçamento do João?" → agente chama tool, recebe linha, responde.

Você acabou de transformar o agente de "respondedor" em "executor".
