01
O que você vai aprender

Por que isso importa

Em uma frase

É a forma mais rápida de ir do zero a um fluxo de captura de leads, intake de cliente, pesquisa, pedido de informação, ou qualquer coisa que envolva "alguém preenche → eu recebo".

Form Trigger é o trigger mais subestimado do n8n. Resolve um problema universal, capturar dados de pessoas via formulário, sem você precisar:

  • Criar conta em Typeform/Google Forms
  • Configurar webhook no meio
  • Mexer com HTML/CSS/JS
  • Pagar por outro SaaS
02
O conceito, e é um só

Conceito central

O conceito desta aula

Form Trigger = você define os campos no n8n, e o n8n te dá uma URL pública com formulário pronto

Quando alguém preenche, dispara o workflow.

  • Entrada: alguém preenche o formulário
  • Saída: 1 item com cada campo do formulário como chave (ex.: { Nome: "Ana", Email: "ana@x.com" })
  • Quando dispara: quando o formulário é enviado (botão Submit)
  • Pré-requisito crítico: workflow precisa estar ativado pra usar URL de produção
Comparação

Form Trigger entrega UI pronta + URL. Webhook só te dá a URL: você teria que construir o formulário separado. Form Trigger é o "atalho" pra captura de dados via formulário.

  • Webhook = só a URL; o formulário é problema seu
  • Form Trigger = a URL e o formulário, prontos

Em sala a analogia foi o balcão de atendimento. Repare no lado direito do slide: o preenchimento vira um item com um campo por pergunta, que é a saída descrita acima.

As 2 URLs (igual ao Webhook)
  • Test URL: pra desenvolver, expira ao fechar.
  • Production URL: pra produção, exige workflow ativo.
Customização básica

Form Trigger permite customizar:

  • Título e descrição do formulário
  • Texto do botão de envio (default: "Submit")
  • Mensagem de resposta (após enviar)
  • CSS customizado pra estilizar (avançado)
Não tente recriar Typeform

Form Trigger é funcional, não é design-heavy. Pra formulários com lógica condicional avançada, branding pesado, multi-página complexo: Typeform ainda ganha (e você integra via webhook). Pra 90% dos casos, Form Trigger é o suficiente.

A demonstração

Exemplo guiado: Form de contato simples

Vamos criar um formulário "Fale conosco":

Exemplo guiado · Form de Contato
  1. Crie workflow novo. Renomeie pra Form de Contato.
  2. Adicione n8n Form Trigger → renomeie pra 📝 Form Contato.
  3. Configure: Form Title Fale com a gente; Form Description Preencha seus dados que retornamos em até 24h.
  4. Em Form Elements, clique em Add Field 3 vezes:
Os 3 campos · label, tipo, obrigatório 
Field Label: Nome     · Type: text     · Required: true
Field Label: E-mail   · Type: email    · Required: true
Field Label: Mensagem · Type: textarea · Required: true
  1. Copie a Test URL e abra em outra aba do navegador.
  2. Veja o formulário pronto. Preencha e envie.
  3. Volta no n8n: você vê o item chegando com os 3 campos.
  4. Pra produção: ative o workflow → use a Production URL no seu site/landing page.

Redesenho do canvas, a partir da execução de teste (execução 418, 16/09/2026). O item que chegou:

Output do 📝 Form Contato 
{
  "submittedAt": "2026-09-16T16:27:16.524Z",
  "Nome": "(seu nome)",
  "E-mail": "voce@exemplo.com",
  "Mensagem": "Quero saber mais sobre o curso de n8n."
}

Repare nas chaves: cada campo vira uma chave com o label exato que você deu, acento e hífen incluídos (E-mail), e o n8n acrescenta submittedAt sozinho. O teste de 16/09 foi feito com o envio de teste do próprio n8n, sem abrir a URL no navegador.

Pronto. Você tem um formulário capturando dados.

05
A cerca

Pegadinhas

Form precisa de workflow ativo pra funcionar fora do dev

Sem Active = ON, a Production URL retorna erro.

Achar que dá pra estilizar como Typeform

Form Trigger tem CSS customizável mas não é editor visual. Se design importa demais, integra com Typeform via Webhook em vez disso.

Esquecer de marcar campos como required

Sem requiredField = true, o usuário pode enviar formulário em branco. Marque required nos campos críticos.

Misturar Test URL e Production URL

Quando você muda do dev pra produção, troque a URL no link que você compartilha (no site, no e-mail, etc.).

Form muito longo = pouca conversão

Se você precisa de 15 campos, considere quebrar em 2-3 páginas (Form Trigger suporta multi-page) ou repensar o que é essencial.
