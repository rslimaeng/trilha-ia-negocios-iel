01
O que você vai aprender

Por que isso importa

Em uma frase

Saber separar uma lista, iterar com freio e juntar os resultados num item só é a diferença entre um fluxo que roda 5 itens de teste e um que aguenta 5.000 em produção.

Workflows reais lidam com listas. 50 leads numa planilha. 200 mensagens não lidas.

A boa notícia: o n8n já itera sozinho: todo nó roda 1 vez por item, automaticamente (revisar aula 2). Os 3 nós desta aula entram quando essa iteração padrão não basta.

Conceito central

O conceito desta aula

Três nós para a lista: separar, processar com freio, juntar

NóO que fazQuando usar
Loop Over ItemsProcessa N itens em lotes, com pausa entre elesRate limit de API; controle granular

Analogia

Split Out é a peneira: "1 saco com 3 maçãs" vira "3 maçãs separadas". Aggregate é a sacola: faz o oposto, empacota N itens num único item. Loop Over Items é o freio de mão: só puxa pra controlar velocidade.

  • A peneira = Split Out
  • A sacola = Aggregate
  • O freio de mão = Loop Over Items

03
Como funciona

Como funciona na prática

Split Out: a peneira

Explode array dentro de 1 item em N itens. "1 saco com 3 maçãs" vira "3 maçãs separadas".

Pra copiar 
Antes: [{ "lead": "Ana", "tags": ["vip","novo","BR"] }]
Depois: [
  { "lead": "Ana", "tags": "vip" },
  { "lead": "Ana", "tags": "novo" },
  { "lead": "Ana", "tags": "BR" }
]

Configuração: nome do campo a separar (tags).

Aggregate: a sacola

Faz o oposto do Split Out. Pega N itens e empacota num único item.

Pra copiar 
Antes (3 itens):
[ { "nome": "Ana" }, { "nome": "Bruno" }, { "nome": "Carla" } ]
Depois (Aggregate em "nome"):
[ { "nome": ["Ana","Bruno","Carla"] } ]
O ciclo

Split Out + Aggregate juntos formam o ciclo "explodir → processar item a item → reagrupar pra entregar". Base de relatórios automáticos sem Code node.

Loop Over Items: o freio

O n8n já processa item por item. Use Loop Over Items só quando:

  1. Rate limit de API: você tem 100 itens, mas a API aceita 10/min. Loop em lotes de 10 + Wait entre eles.
  2. Controle granular entre iterações (raro pra iniciante).
Para 90% dos casos, você não precisa de Loop Over Items

O n8n já itera. Use só com rate limit ou controle granular.

Analogia: freio de mão. Só puxa pra controlar velocidade.

Exemplo guiado: Split Out → Aggregate

Exemplo guiado · explode e junta de volta
  1. Manual Trigger → renomeie ▶️ Disparo.
  2. Edit Fields (Set, modo JSON) → 📦 1 Item com Tags. Cole:
O JSON do item com tags 
{ "lead": "Ana", "tags": ["vip", "novo", "BR"] }
  1. Split Out → 🔪 Explode Tags. Fields To Split Out: tags. Execute → vira 3 itens.
  2. Aggregate → 🛍️ Junta de Volta. Aggregate: Individual Fields. Fields To Aggregate: tags. Execute → volta a ser 1 item com array.

Redesenho do canvas, a partir da execução de teste (execução 445, 16/09/2026). O Split Out entregou 3 itens (vip, novo, BR, cada um com o lead junto) e o Aggregate devolveu { "tags": ["vip", "novo", "BR"] }: 1 item.

Você acabou de fazer o ciclo Split Out → Aggregate.

05
A cerca

Pegadinhas

Achar que precisa de Loop Over Items pra "iterar"

O n8n já itera. Use só com rate limit.

Confundir Split Out com Loop Over Items

Split Out explode array em itens. Loop Over Items agrupa itens em lotes. Funções opostas.

Aggregate sem definir o campo

Sem Fields To Aggregate, ele empacota em estrutura genérica. Confira no JSON view.

Wait de menos = rate limit estoura

Confira o limite real da API.

Wait de mais = workflow lento

5s × 500 itens = 40min.
