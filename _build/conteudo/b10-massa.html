01
O que este bloco é

Cinco fluxos, e o mesmo esqueleto em três deles

Em uma frase

As seis aulas anteriores explicaram o agente por dentro. Esta é a hora de montar: 3 fluxos com Agent (conversacional, Calendar, E-mail) e 2 sem Agent (Triador de PDFs, Classificador de E-mails), cada um em página própria.

Você pode fazer os cinco em sequência ou parar em qualquer um: cada página funciona sozinha e diz no começo o que precisa estar pronto antes.

O que você precisa ter
  • Credencial de LLM configurada (a porta gratuita está no B6, aula 5)
  • Credencial Google (Calendar, Sheets, Gmail) pros fluxos 2 a 5 (o caminho está no B9, aula 3)
  • As aulas 1 a 6 deste bloco entendidas
O que você leva no fim
  • 5 fluxos funcionando: 3 com Agent (conversacional, Calendar, E-mail) + 2 sem Agent (Triador de PDFs, Classificador de E-mails)
  • Um esqueleto reusável de agente, que serve de base pros próximos

Nenhum dos cinco foi executado numa conta de teste em 09/2026. O passo a passo de cada página é o do material, como está; onde o material diz o que esperar, a página diz também, e declara que não foi rodado.

03
Como um puxa o outro

Por que esta ordem

Os três primeiros são o mesmo agente crescendo; os dois últimos são independentes, e provam que nem tudo precisa de Agent.

O que ele deixa prontoO que fica travado sem ele
01 O esqueleto: Chat Trigger + Agent + Memory, com Session ID dinâmico e um System Prompt que responde direito O Fluxo 2 duplica este workflow; errar aqui significa que todo agente seguinte herda o erro
02 O mesmo agente com 2 tools de Calendar, e a primeira ação real O Fluxo 3 aproveita o esqueleto e troca as tools
03 O agente que busca contato no Sheets e envia Gmail com aprovação Nada: é o fecho do ramo com Agent
04 Um triador de PDFs em 4 nós, sem Agent Nada: começa do zero, independente dos três primeiros
05 Um classificador de e-mails em 4 ramos, sem Agent Nada: começa do zero, independente dos outros quatro

A ordem que importa é 1 → 2 → 3. O material diz que os 3 fluxos com Agent têm a mesma anatomia (Chat Trigger → AI Agent → Tools; LLM + Memory iguais; só mudam as tools e o system prompt). O 4 e o 5 você faz na ordem que quiser.

Comece pelo Fluxo prático 1: Agente conversacional simples. As sete aulas do bloco estão na capa do B10.
