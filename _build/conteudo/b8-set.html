Conceito central: Set node

O conceito desta aula

Set é o nó que cria ou modifica campos no item que está fluindo

Tem dois modos:

ModoQuando usar
JSONVocê cola um JSON inteiro de uma vez. Útil pra dado de teste estruturado.

A linha do modo Manual (campo a campo, o que a aula 4 do B6 usou) não veio no export do Notion; a tabela está como chegou.

Analogia

O Set é o organizador da mochila: o que vai no bolso da frente, o que vai no principal, o que sai fora. É a sticky do nó no exemplo-nodes-v2.

  • Arrumar os bolsos = renomear e converter campos
  • Jogar fora o que não serve = Keep Only Set ligado
  • A mochila = o item que segue pro próximo nó

Os dois hábitos desta aula, em slide. O slide escreve "renorear", com erro de digitação; é renomear. A frase de baixo é a pegadinha 3 da cerca.

Padrão de uso 1: combinar campos numa frase
Pra copiar

Padrão de uso 2: limpar dado pra próxima etapa
Pra copiar 
Input:  { "lead_full_name": "Ana Silva", "lead_email_address": "ana@x.com", "internal_id": 42 }
Set (Keep Only Set ligado):
  - nome:  {{ $json.lead_full_name }}
  - email: {{ $json.lead_email_address }}
Output: { "nome": "Ana Silva", "email": "ana@x.com" }
Padrão de uso 3: converter tipo
Pra copiar 
Input:  { "score": "85" }   ← string (cuidado!)
Set:    score = {{ Number($json.score) }} → Type: Number
Output: { "score": 85 }     ← number (IF agora funciona)

Pinning de dados: o hábito que economiza horas

Pinning trava o output de um nó como se fosse o resultado real. Os nós seguintes acreditam que o dado pinado é o output verdadeiro e rodam a partir dele: sem precisar disparar o trigger de novo.

Por que importa. Imagine um workflow Webhook Trigger → AI Agent → Sheets:

  • Sem pinning: cada teste do Sheets você manda nova requisição no Webhook.
  • Sem pinning: cada teste re-roda o AI Agent (paga OpenAI de novo).
  • Com pinning no Webhook: você dispara 1 vez, pinna, e itera no resto do fluxo sem reenviar.
Em uma frase

"Sem pinning, você re-roda o webhook 50 vezes pra testar uma mudança no Gmail. Com pinning, dispara 1 vez."

Como pinar e despinar
  1. Pinar: com o nó selecionado, pressione P depois de uma execução boa. Aparece um pino no canto.
  2. Despinar: pressione P de novo no nó pinado. Pino some.
Quando despinar: obrigatório antes de ativar produção

Pinned data ativo num workflow ativado faz ele rodar com dado fixo, ignorando o trigger real. Sintoma: workflow ativado parece "rodar" mas processa sempre os mesmos dados. Sempre despine antes de ativar.

A demonstração

Exemplo guiado: Set + Pinning juntos

Exemplo guiado · Lead Bruto, Lead Limpo
  1. Manual Trigger → renomeie ▶️ Disparo.
  2. Set node (modo JSON) → renomeie 📦 Lead Bruto. Cole:
O JSON do Lead Bruto 
{
  "lead_full_name": "Ana Silva",
  "lead_email_address": "ana@empresa.com",
  "lead_score_str": "85",
  "internal_id_legacy": "abc-123"
}
  1. Execute. Pinne (P): o pino aparece.
  2. Set node (modo Manual, Keep Only Set ligado) → renomeie 🧹 Lead Limpo. Configure:
Os 3 campos do Lead Limpo · nome, tipo, expression 
nome  (String, Expression): {{ $('📦 Lead Bruto').item.json.lead_full_name }}
email (String, Expression): {{ $('📦 Lead Bruto').item.json.lead_email_address.toLowerCase() }}
score (Number, Expression): {{ Number($('📦 Lead Bruto').item.json.lead_score_str) }}
  1. Execute. Output limpo:
Output do 🧹 Lead Limpo (execução 434) 
{ "nome": "Ana Silva", "email": "ana@empresa.com", "score": 85 }

Redesenho do canvas, a partir da execução de teste (execução 434, 16/09/2026). O score saiu 85 sem aspas: o Number() do padrão 3 funcionou, e o internal_id_legacy ficou de fora, que é o Keep Only Set. Na versão atual do n8n a opção se chama Include Other Input Fields: desligada, é o mesmo que Keep Only Set ligado.

Agora itere no 🧹 Lead Limpo mudando configurações, sem reexecutar o 📦 Lead Bruto, porque ele tá pinado.

05
A cerca

Pegadinhas

Keep Only Set desligado quando você queria limpar

O output sai com todos os campos antigos + os novos. Verifique sempre.

Tipo errado

Number virando String ("85" em vez de 85) quebra IF/Switch silenciosamente. Sempre confira no JSON view do output.

Esquecer pinned data despinado em produção

O workflow ativado roda com dado fake. Pino antes de ativar = bug em produção.

Pinar dado sensível

Se você pina um Webhook que recebeu token/senha de teste, esse dado fica gravado no workflow exportado. Limpe antes de compartilhar.

Renomear o nó depois de pinar

O pinned data fica órfão. Renomeie antes.
