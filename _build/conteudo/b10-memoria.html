O que você vai aprender

Por que isso importa

Em uma frase

Sem memória, cada mensagem é tratada como se fosse a primeira. O usuário diz "meu nome é Ana", e na mensagem seguinte o agente pergunta o nome de novo.

Mas o erro que vai te custar mais tempo não é esquecer de adicionar memória: é configurar o Session ID errado e fazer o agente misturar dados de pessoas diferentes em produção.

Conceito central

O conceito desta aula

Três tipos de memória, e uma só interessa na v1

No n8n existem 3 tipos de memória pro agente. Pra v1 do curso, uma só interessa: Simple Memory.

Simple Memory: a recomendada pra começar

  • Guarda as últimas N mensagens (default: 5; ajustável).
  • Vinculada a um Session ID (e-mail, chat_id, número da linha).
  • Apaga ao reiniciar o workflow ou após período sem uso.

Conferido em 21/09/2026 na definição do nó Simple Memory (versão 1.3): o campo Context Window Length tem padrão 5, "how many past interactions the model receives as context".

03
Como funciona

Como funciona na prática: o Session ID

O Session ID é o rótulo que o nó de Memória usa pra agrupar mensagens da mesma conversa. Sem ele bem configurado, todas as execuções viram uma "conversa única" gigante.

Por que o Session ID é crítico

Imagine um agente Telegram:

  • Ana manda: "quero comprar 10 unidades"
  • Bruno manda 30 segundos depois: "qual o preço?"
Session ID fixo "sessao1"

O agente "lembra" da Ana ao responder o Bruno → Bruno recebe resposta de "10 unidades por R$ X": informação que não é dele.

Session ID = ID do usuário do Telegram

Cada conversa isolada → Bruno recebe resposta que faz sentido pra ele.

Padrões errados

Três Session IDs que quebram em produção 
"sessao1"        ← fixo: mistura todo mundo
"teste"          ← ficou em modo de teste e foi pra produção
{{ $now }}       ← cada execução vira sessão nova; agente esquece tudo

Configurando Simple Memory

  1. No AI Agent, clique no + da porta Memory.
  2. Selecione Simple Memory.
  3. Session ID Type: mude pra Customize Session ID.
  4. Key: cole a Expression apropriada.
  5. Context Window Length: mantenha 5 (default).

Conferido em 21/09/2026 na definição do nó (Simple Memory 1.3): o campo se chama Session ID e tem duas opções, Connected Chat Trigger Node (o padrão, que já usa {{ $json.sessionId }}) e Define below, que é o "Customize Session ID" do material, onde você cola a Expression. Com Chat Trigger, o padrão já resolve; pra Telegram, Webhook, planilha e e-mail é o "Define below".
