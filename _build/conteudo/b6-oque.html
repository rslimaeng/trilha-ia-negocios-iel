O que você vai aprender

Por que isso importa

Em uma frase

Toda segunda às 9h você abre 3 sistemas, copia números, cola numa planilha, formata e manda pro time por e-mail. Toda. Segunda. Em um ano, são 100 horas, quase 3 semanas de trabalho, gastas em algo que ninguém precisa fazer manualmente. Esse é o problema que o n8n resolve.

Empresas e profissionais perdem horas por dia em tarefas que se repetem: copiar dados de uma planilha pra outra, mandar e-mail toda segunda às 9h, registrar lead que chega pelo formulário. n8n é a ferramenta que monta esses fluxos visualmente, sem você precisar escrever código.

A pergunta certa não é "vale a pena automatizar isso?": é "o que ainda estou fazendo na mão que poderia rodar sozinho?".

A cena da aula presencial. A pergunta do lado direito é a mesma desta seção, e é a que abre cada bloco daqui em diante.

02
O conceito, e é um só

Conceito central

O conceito desta aula

n8n é uma plataforma de automação de fluxos

Você arrasta blocos numa tela, conecta com setas, e o n8n executa um após o outro.

Cada bloco se chama node (em português, "nó"). Cada nó tem uma função: enviar e-mail, ler planilha, chamar uma IA, fazer uma decisão. A sequência de nós conectados é um workflow (fluxo de trabalho).

Analogia

Pense em uma receita de bolo. Os ingredientes são os dados que entram. Cada passo da receita é um nó. O bolo pronto é o resultado. n8n é a cozinha que executa a receita do começo ao fim, sem você precisar mexer em cada panela.

  • Ingredientes = os dados que entram
  • Cada passo da receita = um nó
  • O bolo pronto = o resultado
  • A cozinha = o n8n

A receita, desenhada. Repare que a bandeja é a cozinha: os três quadros acontecem dentro dela, e é isso que o n8n é.

Resumo honesto

Se você quer um Zapier que não trava no preço e que aceita lógica mais sofisticada, n8n é a escolha. Se você só vai automatizar 3 coisas simples, Zapier é mais rápido de aprender.

A mesma comparação, em três linhas. A última frase do slide já responde a pergunta seguinte: Cloud, pra começar rápido.

n8n Cloud vs self-host: a escolha do iniciante

n8n pode rodar de dois jeitos:

  • n8n Cloud: plataforma gerenciada pela própria n8n. Você só usa, sem instalar nada.
  • Self-host: você instala n8n no seu computador ou num servidor. Mais controle, mais responsabilidade.
Critérion8n CloudSelf-host
SetupCadastro em 2 minDocker / VPS / config
CustoTrial 14 dias + planos pagosGratuito (custo de servidor)
ManutençãoZero (n8n cuida)Sua (atualizar, backup)
HTTPS / domínioProntoVocê configura
Ideal praIniciante / módulo v1Quem já tem familiaridade com terminal

Pra v1 do módulo, sempre n8n Cloud. Self-host fica como trilha avançada: não é tema deste módulo.

Pegadinha comum

Querer self-hostar antes de entender o que é workflow. Resultado: gasta 3 horas configurando Docker e ainda não construiu o primeiro fluxo. Comece pelo Cloud, escale depois.

03
Como funciona

Como funciona na prática

Todo fluxo no n8n tem 3 partes obrigatórias:

01

Um trigger (gatilho)

É o que dispara o fluxo. Pode ser: clique manual, horário marcado, recebimento de e-mail, formulário enviado, ou qualquer outro evento.

02

Um ou mais nós de ação

Cada um faz uma coisa: ler dado, transformar, enviar pra outro lugar.

03

Conexões entre os nós

Setas que dizem "depois deste, vai pra aquele".

Quando o trigger dispara, os dados fluem pelos nós, na ordem das conexões. Cada nó recebe o resultado do anterior, processa, e passa adiante.

Modelo mental

"input vem da esquerda, processo no meio, output sai à direita". Isso vale pra cada nó, e vale pro workflow inteiro. É fractal: a mesma estrutura se repete em escalas diferentes.
