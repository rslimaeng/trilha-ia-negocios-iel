01
Para que serve

"Parece funcionar" não é validação

Em uma frase

Antes de declarar um fluxo pronto, ele tem que passar nos três pontos abaixo. Sem exceção.

02
Os três pontos

Um de cada vez, nesta ordem

1 · Nenhum nó vermelho

Abra o painel de execuções e olhe a última. Todos os nós estão verdes ou cinza? Vermelho é erro, mesmo que o resultado pareça ter chegado.

2 · O resultado tem o formato esperado

Olhe o resultado do último nó. Os campos esperados estão lá? Os valores fazem sentido? Os tipos estão certos?

3 · O caso de borda foi testado

Rode com entrada fora do padrão. Caso de borda é mais comum que caso perfeito.

O erro do ponto 2 que mais passa despercebido

A IA devolveu "score": "85", com aspas, em vez de "score": 85. O fluxo não dá erro, mas a comparação score > 70 no IF seguinte falha em silêncio. É o assunto da aula 1 do B8.

O ponto 3, em quatro perguntas

  • E se o campo vier vazio?
  • E se a IA devolver um formato inesperado?
  • E se a planilha tiver 0 linhas?
  • E se o texto tiver acento ou emoji?

Se o fluxo só funciona com entrada perfeita, ele vai quebrar em produção. A pergunta não é se a entrada imperfeita vai chegar, é quando.

03
Quando aplicar

Obrigatório e recomendado

Obrigatório ao final de
  • Todo fluxo prático de uma aula
  • Todo projeto do B11
  • Qualquer fluxo antes de ativar em produção
Recomendado

Depois de cada bloco novo, mesmo durante a construção. Pegar erro cedo é mais barato que pegar tarde.

Para colar no comentário do fluxo 
☐ Nenhum nó vermelho na última execução
☐ Output final tem todos os campos esperados, com tipos corretos
☐ Caso de borda testado: __________________ (descrever)
☐ Resultado do caso de borda: ____________________
04
Quando falha

Sintoma e onde olhar

SintomaOnde provavelmente está o problema
Nó vermelho com erro de credencialReconfigurar a credencial do nó: o acesso pode ter expirado
Resultado vazio, sem erroMerge no modo errado, ou Limit node esquecido
Tipo de dado erradoFalta conversão: use o Set com Number() ou String()
O agente não chama uma ferramentaA ferramenta não está mencionada no System Prompt. Ver Reactive Prompting
Funciona às vezes, falha às vezesCaso de borda não tratado
Mensagem chega com dado de outra pessoaSession ID fixo. Ver o glossário
