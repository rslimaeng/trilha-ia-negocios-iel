O que você vai aprender

Por que isso importa

Em uma frase

Esses triggers são o caminho fácil quando o app que você usa já tem integração nativa no n8n. Faz a diferença entre "automatizei em 10 minutos" e "perdi a tarde configurando webhook do Gmail".

Pra muita coisa do dia a dia (Gmail, Google Drive, Google Calendar, Slack, Telegram, Notion, etc.), o n8n tem triggers prontos que escutam eventos desses apps. Você não precisa configurar webhook, mexer com API, nem entender de OAuth a fundo.

02
O conceito, e é um só

Conceito central

O conceito desta aula

App Event Trigger = trigger nativo de um app específico, que escuta eventos lá e dispara o workflow

Exemplos:

  • Gmail Trigger: quando chega um e-mail novo (com filtros: label, from, subject, etc.)
  • Google Sheets Trigger: quando uma nova linha é adicionada
  • Google Drive Trigger: quando aparece arquivo novo numa pasta
  • Telegram Trigger: quando chega mensagem no bot
  • Slack Trigger: quando alguém menciona o bot ou poste em canal

Cada trigger tem opções específicas do app: tipo de evento, filtros, frequência de checagem.

Comparação

Webhook é genérico (qualquer sistema). App Event é específico (1 app). Use app event quando o app oficial está disponível; use Webhook quando o app não tem nó nativo no n8n.

  • Tem nó nativo = App Event Trigger
  • Não tem = Webhook

Polling vs Push: a diferença que importa

Cada app event trigger funciona de um jeito por baixo:

TipoComo funcionaDelay típico
Pollingn8n pergunta pro app "tem coisa nova?" a cada X minutos1-15 min
PushApp avisa o n8n imediatamente quando algo aconteceSegundos

A maioria dos triggers de app no n8n usa polling (Gmail, Sheets, Drive). Alguns usam push (Telegram bot).

Implicações:

  • Polling tem delay: chegou e-mail às 10h00, n8n só vê às 10h05 (se estiver checando a cada 5 min).
  • Polling consome créditos: cada checagem é 1 execução no plano. A cada 1 min = 1.440 execuções/dia. Cuidado com plano básico.
  • Push é instantâneo, mas exige config mais complexa do app.
Não use polling pra real-time

Se você precisa reagir em segundos (ex.: chatbot, atendimento ao vivo), use Webhook ou Telegram trigger (push). Polling pra real-time = frustração.

Polling e push, como foram mostrados em sala. O carteiro que abre a caixa a cada 5 minutos é a tabela acima em desenho; o celular que apita é o Telegram.

03
Como funciona

Como funciona na prática (Gmail Trigger como exemplo)

Pré-requisito comum: credencial / OAuth

Pra usar quase qualquer app event trigger, você precisa autorizar o n8n a acessar sua conta (Gmail, Drive, etc.): isso é a credencial.

A primeira vez é chata: você cria projeto no Google Cloud Console, ativa APIs, gera OAuth client, autoriza no n8n. Depois disso, a credencial fica salva e você reusa em vários workflows.

Como esse setup é repetitivo e bloqueante, trataremos OAuth em vídeo standalone: assim você assiste uma vez e tira o trauma. Pra esta aula aqui, foco no conceito dos app event triggers, não no setup. (Na trilha, o passo a passo da credencial Google está na aula 3 do B9.)

Configuração típica

  1. Adicione Gmail Trigger.
  2. Credential: conecte sua conta Google (ou use credencial já salva).
  3. Event: escolha "Message received" (chegou e-mail novo).
  4. Filters (opcionais):
    • Label IDs: só dispara em e-mails com determinado label
    • From: só de remetentes específicos
    • Subject: só com assunto específico
  5. Polling Time: a cada quanto checa (default: 1 min, cuidado com créditos)
  6. Simplify: false se você quer body completo do e-mail (recomendado)
O que sai

Cada e-mail novo vira 1 item com from, to, subject, body, attachments, etc.

05
A cerca

Pegadinhas

Polling tem delay (1-15 min). Não use pra real-time

Quem precisa de resposta em segundos usa Webhook ou Telegram (push).

Cada execução de polling consome créditos

A cada 1 min = 1.440 execuções/dia. Calcule antes de configurar polling agressivo no plano básico.

OAuth Google é fricção real

Primeira vez leva 30-60 min. Vale fazer uma vez e reusar a credencial em todos os workflows.

Workflow precisa estar ativo pra polling rodar

Test mode só dispara no clique de "Listen for Test Event". Polling real exige Active = ON.

Filters mal configurados fazem trigger não disparar nunca

Se você botou filtro de label "trabalho" mas o e-mail veio sem label, nada acontece. Teste com filtros mais largos primeiro, restrinja depois.
